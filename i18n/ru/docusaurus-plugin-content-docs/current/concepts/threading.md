# Потоки и главный поток

Объекты игры принадлежат её главному потоку. Все колбэки мода и события SDK выполняются в нём, если на странице не
сказано иное. Работа в другом потоке (загрузка, долгий расчёт) должна вернуться в главный поток, прежде чем трогать
игру.

## Dispatcher {/* #dispatcher */}

`Dispatcher.MainThread` из `Mjolnir.SDK.Threading` — это и есть главный поток:

| Член | Что это |
|---|---|
| `Post(action)` | Выполняет действие в главном потоке в начале следующего кадра, в том числе при вызове из него |
| `CheckAccess()` | Находится ли вызывающий в главном потоке. Во время `OnLoad`, пока игра не готова, главным считается любой поток |
| `VerifyAccess()` | Бросает исключение, если вызывающий не в главном потоке |

```csharp
_ = System.Threading.Tasks.Task.Run(() =>
{
    // Вне главного потока: файловый ввод-вывод, никаких объектов игры.
    string folder = System.IO.Path.GetDirectoryName(Manifest.Location)!;   // Location — .dll мода
    string notes = System.IO.File.ReadAllText(System.IO.Path.Combine(folder, "notes.txt"));
    Dispatcher.MainThread.Post(() => Notify.Message(notes));
});
```

Исключение из отправленного действия отключает мод, который его отправил, как и из любого другого обработчика.

## await {/* #await */}

У главного потока есть контекст синхронизации, который отправляет работу диспетчеру. Код, выполняющий `await` в
главном потоке, продолжается в нём же, в начале одного из следующих кадров:

```csharp
Menus.Pause.Add(new UiButton { Content = "Reset" }).OnClick(async () =>
{
    if (await Dialog.ConfirmAsync("Reset", "Start over?"))
        Notify.Message("Reset");   // снова в главном потоке
});
```

## Что безопасно из других потоков {/* #what-is-safe-from-other-threads */}

- **Элементы UI.** Свойства элемента управления можно менять из любого потока. Модель меняется сразу, а то, что на
  экране, следует за ней в следующем кадре. `Children` панели нужно менять в главном потоке или в `Post`.
- **Характеристики.** Чтение `PlayerStat` или `CharacterStat` из другого потока даёт значение, последним увиденное в
  главном потоке; запись применяется в следующем кадре.
- **Консоль.** `DevConsole.Execute` и `Print` работают из любого потока; команды выполняются в главном потоке.
- **Локализация.** `Localization.Get` находит строки модов где угодно, а строки игры — только в главном потоке.
- **Всё остальное**, что трогает игру, её объекты Unity и обёртки Il2CppInterop, требует главного потока.
