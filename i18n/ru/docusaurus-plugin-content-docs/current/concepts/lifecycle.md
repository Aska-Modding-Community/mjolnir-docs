# Жизненный цикл мода

Сборка мода содержит ровно один неабстрактный класс, производный от `Mod`, с атрибутом `[ModManifest]` и открытым
конструктором без параметров. Mjolnir создаёт этот класс и вызывает его виртуальные методы. Сборка без такого класса —
библиотека: она может лежать в папке мода, и мод может на неё ссылаться.

## Манифест {/* #the-manifest */}

```csharp
[ModManifest("author.mymod", "My Mod", "1.2.0",
             Description = "What it does, in one line.",
             Author = "Author",
             Network = NetworkCompatibility.Everyone,
             Icon = "art/icon.png")]
[ModDependency("author.library", ">=1.0 <2.0")]
[ModDependency("author.extras", "*", Optional = true)]
public sealed class MyMod : Mod
{
}
```

| Поле | Значение |
|---|---|
| id | Постоянный идентификатор мода: имя его файла конфига, то, от чего зависят другие моды, основа id его контента. Буквы, цифры, `.`, `_` и `-`, первым символом буква или цифра, сравнивается без учёта регистра. По соглашению — `author.mod`. `mjolnir` зарезервирован |
| name | То, что видит игрок. Пустое имя заменяется id |
| version | `Major[.Minor[.Patch[.Revision]]]`. Суффикс `-prerelease` или `+build` допустим и при сравнении не учитывается |
| `Description` | Одна строка под именем мода в окне модов |
| `Author` | Показывается рядом с версией |
| `Network` | Кому мод нужен в сетевой игре: `Everyone` (по умолчанию), `ClientOnly` или `ServerOnly` |
| `Icon` | PNG или JPG относительно папки `.dll` мода. Без него берётся лежащий там `icon.png`. Без него окно показывает первую букву имени |

Мод с неверным id или версией не загружается; причина — в логе.

:::note
Каждая сетевая сессия сравнивает моды `Everyone` подключающегося клиента с модами хоста. См.
[Мультиплеер](../guides/network.md#the-mod-check).
:::

### Зависимости {/* #dependencies */}

`[ModDependency(id, versionRange)]` загружает ваш мод после другого, а без него не загружает вовсе.

- Диапазон — список границ, которые должны выполняться все, через пробелы или запятые: `>=`, `>`, `<=`, `<`, `=`.
- Версия без оператора — минимум: `"1.2"` означает `>=1.2.0`.
- `*` или пустой диапазон принимает любую версию. Недостающие компоненты считаются за 0.
- `Optional = true` загружает ваш мод и без другого. Если другой есть, ваш мод загружается после него, и его версия
  всё равно должна попадать в диапазон.

Мод не загружается, если обязательная зависимость отсутствует, выключена игроком или сама не загружена, либо если
любая имеющаяся зависимость вне своего диапазона. Правило действует по всей цепочке; моды в цикле зависимостей тоже
пропускаются. Каждый пропуск записывается в лог с причиной и показывается в окне модов.

Моды сортируются топологически, при равенстве — по id, поэтому порядок одинаков при каждом запуске. Из двух модов с
одним id побеждает первый найденный.

`ModRegistry` перечисляет загруженные моды:

```csharp
if (ModRegistry.TryGet("author.extras", out ModManifest extras))
    Log.Info($"Extras {extras.VersionText} is here");
```

## Колбэки {/* #callbacks */}

| Колбэк | Когда | Типичное применение |
|---|---|---|
| конструктор, `OnLoad()` | Один раз, при запуске, в порядке зависимостей | Конфиг, патчи Harmony, подписки на события, регистрация контента |
| `OnGameReady()` | Один раз, когда движок запущен | Всё, что требует объектов Unity: текстуры, спрайты, заранее созданные окна |
| `OnSceneLoaded(scene, mode)` | При каждой загрузке сцены: сцены загрузчика, главного меню, каждого мира | Реакция на загрузку мира |
| `OnUpdate()` | Каждый кадр | Покадровая работа |
| `OnLateUpdate()` | Каждый кадр, после всех `Update` | Следование за тем, что сдвинулось в этом кадре |
| `OnFixedUpdate()` | Каждый шаг физики | Физика |

Подписываются только переопределённые колбэки: непереопределённый колбэк ничего не стоит.

```csharp title="LifecycleMod.cs"
using Mjolnir.SDK;
using UnityEngine.SceneManagement;

namespace LifecycleMod;

[ModManifest("author.lifecycle", "Lifecycle", "1.0.0")]
public sealed class LifecycleMod : Mod
{
    public override void OnLoad() => Log.Info("Phase A: no Unity objects yet");

    public override void OnGameReady() => Log.Info("Phase B: the engine is up");

    public override void OnSceneLoaded(Scene scene, LoadSceneMode mode) => Log.Info($"Scene {scene.name}");
}
```

## Две фазы {/* #two-phases */}

Движок запускается после `OnLoad`.

| Фаза | Когда | Разрешено |
|---|---|---|
| A | Внутри запуска среды выполнения игры, до запуска движка Unity. Здесь выполняются конструктор и `OnLoad` | Логирование, конфиг, патчи Harmony, регистрации. **Никаких объектов Unity** |
| B | С первого колбэка сцены от движка, примерно через полторы секунды | Всё. Начало отмечает `OnGameReady`, затем идут покадровые колбэки |

Всё, что SDK регистрирует в фазе A, само дожидается игры: элементы HUD, пункты меню, вкладки, предметы, рецепты,
работы, команды консоли. Текстуру, спрайт или `GameObject` в фазе A создать нельзя: окна с картинками создавайте при
первом использовании или в `OnGameReady`.

## Что есть у каждого мода {/* #what-every-mod-has */}

| Член | Что это |
|---|---|
| `Manifest` | Его id, имя, версия, зависимости, путь к его `.dll` (`Location`) и то, отключён ли он после ошибки (`IsDisabled`) |
| `Log` | `Debug`, `Info`, `Warn`, `Error`, пишутся в `Mjolnir/LogOutput.log` с именем мода в префиксе |
| `Config` | Его файл настроек, создаётся при первом использовании. См. [Конфиг](config.md) |
| `Harmony` | Экземпляр HarmonyX с id мода, создаётся при первом использовании. См. [Патчи Harmony](harmony.md) |

Все четыре работают и в конструкторе: Mjolnir подставляет их до создания мода.

## Ошибки {/* #faults */}

Исключение из любого колбэка или из обработчика, переданного модом в SDK (событие, команда, работа), отключает только
этот мод:

- его колбэки и обработчики больше не вызываются;
- в окне модов он помечен как отключённый после ошибки, а исключение есть в логе;
- его патчи Harmony остаются, потому что их нельзя надёжно отменить.

Игра и остальные моды продолжают работать. Сам Mjolnir так никогда не отключается.

## Папка мода {/* #the-mods-folder */}

```text
Mjolnir/Mods/MyMod/
├─ MyMod.dll        мод и библиотеки, которые он приносит
├─ icon.png         его картинка в окне модов
├─ lang/            тексты на языке игрока: english.toml, russian.toml…
├─ items/           картинки его предметов и эффектов (PNG)
└─ bundles/         его AssetBundle (модели)
```

Каждая папка первого уровня в `Mjolnir/Mods` получает свой контекст загрузки сборок, поэтому два мода могут принести
разные версии одной библиотеки. Собственные сборки Mjolnir и interop-сборки игры всегда берутся из одной общей копии,
что бы ни лежало в папке мода, поэтому моды могут передавать друг другу объекты игры и типы SDK.

Пока игра работает, моды никогда не выгружаются. Выключение мода в окне модов действует со следующего запуска.
