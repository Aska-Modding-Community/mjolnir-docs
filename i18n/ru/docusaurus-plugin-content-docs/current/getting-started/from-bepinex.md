# Переход с BepInEx

Mjolnir — отдельный загрузчик со своим рантаймом и своим API: плагин BepInEx под Mjolnir не работает, а мод Mjolnir
не работает под BepInEx. Большая часть знакомого переносится — тот же C#, тот же Harmony, — а сам перенос плагина это
в основном удаление кода: то, что он патчил сам, в SDK уже есть.

## Что остаётся прежним {/* #what-stays-the-same */}

- C#, собранный под игру и работающий на CoreCLR внутри процесса игры, с обёртками Il2CppInterop над типами IL2CPP.
- [HarmonyX](https://github.com/BepInEx/HarmonyX): те же атрибуты `[HarmonyPatch]`, префиксы и постфиксы, тот же
  `PatchAll()`. См. [Патчи Harmony](../concepts/harmony.md).
- Одна сборка на мод, его настройки в файле, его строки в общем логе.

## Что меняется {/* #what-changes */}

| | BepInEx 6 IL2CPP | Mjolnir |
|---|---|---|
| Как попадает в процесс | `winhttp.dll` и Doorstop | `version.dll` рядом с `Aska.exe`; `il2cpp_init` находится по имени, ни один адрес не зашит |
| Рантайм | .NET 6 | .NET 10, приватный, в `Mjolnir/dotnet` |
| C#-представление игры | `BepInEx/interop`, создаётся при первом запуске | `Mjolnir/interop`, создаётся под сборку игры и заново после каждого её обновления |
| Куда кладётся мод | `BepInEx/plugins` | `Mjolnir/Mods/<mod>/`, каждый в своём контексте загрузки |
| Точка входа | `[BepInPlugin]` на `BasePlugin`, `Load()` | `[ModManifest]` на `Mod`, `OnLoad()` и дальше обратные вызовы жизненного цикла |
| Объекты Unity | мод внедряет и держит их сам | `OnGameReady` и покадровые вызовы, после того как движок поднялся |
| Настройки | `Config.Bind(section, key, value, description)` | тот же вызов плюс диапазон и отображаемое имя; их правит окно в игре |
| Лог | `Log.LogInfo(...)` | `Log.Info(...)` |
| Типы самой игры | каждый мод патчит их сам | фасад SDK на каждую область; переименование в игре исправляется в нём, а не в модах |

## Что добавляет платформа {/* #what-the-platform-adds */}

- **Изоляция ошибок.** Любой вызов в мод идёт через платформу: первое же исключение отключает только этот мод, его
  зависимые не загружаются, а игра и остальные моды продолжают работать. Сбой самого загрузчика никогда не роняет
  игру — он пишется в лог, и игра запускается без модов.
- **Моды объявляются, а не угадываются.** Манифест даёт моду идентификатор, версию и зависимости с диапазонами
  версий; они разрешаются и упорядочиваются до того, как что-либо загрузится, и каждый пропуск пишется в лог с
  причиной.
- **API вместо внутренностей игры.** [SDK](../intro.md#the-sdk) покрывает игрока, интерфейс, контент, жителей, бой,
  анимации, часы мира, рельеф, камеру и сеть. Его публичные сигнатуры используют только типы .NET, Unity и
  TextMeshPro, поэтому переименование в игре поглощается внутри SDK, а моды продолжают работать.
- **Мультиплеер, который знает о модах.** Моды подключающегося игрока сверяются с модами хоста, а сами моды
  разговаривают по своим [каналам](../guides/network.md). Идентификаторы контента выводятся из идентификатора мода и
  названия вещи, поэтому совпадают на всех машинах.
- **Одно окно для игрока.** Моды перечислены, включаются, выключаются и настраиваются в меню самой игры, по тем
  настройкам, которые мод объявил: отдельный плагин для конфигурации не нужен.
- **Язык игрока.** Строки мода и замены текстов самой игры идут через [локализацию](../concepts/localization.md).

## Перенос плагина {/* #porting-a-plugin */}

```csharp title="Плагин BepInEx"
[BepInPlugin("author.lightfoot", "Lightfoot", "1.0.0")]
public class Plugin : BasePlugin
{
    public override void Load()
    {
        var cost = Config.Bind("Stamina", "CostMultiplier", 0.5f, "Part of the game's stamina cost.");
        new Harmony("author.lightfoot").PatchAll();
        Log.LogInfo("Loaded");
    }
}
```

```csharp title="Мод Mjolnir"
[ModManifest("author.lightfoot", "Lightfoot", "1.0.0")]
public sealed class Lightfoot : Mod
{
    public override void OnLoad()
    {
        ConfigEntry<float> cost = Config.Bind("Stamina", "CostMultiplier", 0.5f, "Part of the game's stamina cost.")
                                        .WithRange(0f, 1f);

        // Патч, который нёс этот плагин, здесь — событие.
        LocalPlayer.Stamina.Draining += (_, e) => e.Amount *= cost.Value;
        Log.Info("Loaded");
    }
}
```

По шагам:

1. **Проект.** Библиотека классов `net10.0` со ссылками на файлы установленного Mjolnir, а не на пакеты BepInEx:
   `.csproj` есть в [Вашем первом моде](first-mod.md).
2. **Класс.** `BasePlugin` становится [`Mod`](../concepts/lifecycle.md), `[BepInPlugin]` — `[ModManifest]`, а
   `Load()` — `OnLoad()`. Идентификатор оставьте прежним: по нему называется файл настроек и выводятся
   идентификаторы контента мода.
3. **Работа с Unity уходит из `OnLoad`.** `OnLoad` выполняется до того, как поднимется движок. Всё, что трогает
   `GameObject`, переносится в `OnGameReady`, `OnSceneLoaded` или покадровые вызовы; работа из другого потока идёт через
   [диспетчер](../concepts/threading.md).
4. **Настройки.** `Config.Bind` сохраняет форму и пишет `Mjolnir/Config/<id мода>.toml`. Добавьте `WithRange` и
   `WithDisplayName` — и настройка станет ползунком в окне модов.
5. **Уберите патчи, которые покрывает SDK.** Здоровье и расход выносливости игрока, интерфейс, предметы, рецепты,
   постройки, жители и их работы, бой, анимации, камера и рельеф — это фасады с событиями, см. руководства. Сырой
   Harmony остаётся доступен через `Mod.Harmony` для всего остального.
6. **Мультиплеер.** Пока мод не сказал иного, он `ClientOnly`. Объявите
   [совместимость](../guides/network.md) мода как `Everyone`, если он должен быть у каждого игрока (свой контент,
   сообщения остальным), — чтобы сессия с несовпадающими модами была отклонена со списком различий, а не
   сломалась позже.
7. **Выпуск.** Одна папка в `Mjolnir/Mods/` с `.dll` мода и его собственными файлами. Ничего из платформы туда не
   копируется: копия сборки SDK в папке мода игнорируется.

## Один загрузчик за раз {/* #one-loader-at-a-time */}

Mjolnir и BepInEx запускают в процессе игры каждый свой рантайм .NET и свой Il2CppInterop. Вместе они не
проверялись, поэтому ставьте что-то одно: чтобы вернуться к BepInEx, удалите `version.dll`; чтобы запустить игру
вообще без загрузчика, добавьте `--no-mods`.

## Что по-прежнему даёт BepInEx {/* #what-bepinex-still-gives-you */}

BepInEx работает на сотнях игр и ставится менеджерами модов вроде Thunderstore Mod Manager и r2modman. Mjolnir сделан
только для ASKA, ставится распаковкой архива в папку игры, и его экосистема ровно такого же возраста, как эта
документация. Выбирайте его за то, что даёт платформа, а не потому, что без неё плагин написать нельзя.
