# Установка

Mjolnir устанавливается в папку игры и не меняет ни одного файла игры. Чтобы удалить его, достаточно удалить один файл.

## Установка {/* #install */}

1. Скачайте `Mjolnir-<version>.zip` со страницы
   [релизов](https://github.com/FibonacciFox/Mjolnir/releases). Рядом с каждым архивом лежит файл `.sha256`, если
   хотите проверить загрузку.
2. Распакуйте его в папку игры, ту, где лежит `Aska.exe`. В Steam: **ASKA → Управление → Просмотреть локальные файлы**.
   В архиве только `version.dll` и папка `Mjolnir/`.
3. Запустите игру из Steam как обычно.

При первом запуске Mjolnir генерирует C#-представление кода игры для вашей сборки игры. Это показывает окно прогресса, и
занимает это около полуминуты. Затем игра запускается сама. То же происходит после каждого обновления игры и каждого
обновления Mjolnir, а все остальные запуски этот шаг пропускают.

Кнопка окна прогресса останавливает генерацию и запускает игру без модов. Генерация снова выполнится при следующем
запуске.

## Добавление модов {/* #add-mods */}

Положите каждый мод в отдельную папку внутри `Mjolnir/Mods/`:

```text
ASKA/
├─ Aska.exe
├─ version.dll
└─ Mjolnir/
   └─ Mods/
      ├─ SomeMod/
      │  └─ SomeMod.dll
      └─ AnotherMod/
         ├─ AnotherMod.dll
         └─ lang/
```

Моды, которым нужны другие моды, загружаются после них. Мод с отсутствующей зависимостью или с зависимостью версии,
которую он не принимает, пропускается, и окно модов объясняет почему.

## Окно модов {/* #the-mods-window */}

**Главное меню или меню паузы → Mjolnir** открывает список установленных модов: имя, версию, автора и статус каждого.
В его строке есть:

- переключатель **Выкл / Вкл**, который действует со следующего запуска (заметка в нижней части окна говорит, что
  нужен перезапуск);
- кнопка **Настройки**, открывающая страницу настроек мода.

Если вы выключаете мод, который нужен другим, окно сначала спрашивает. Если вы включаете мод, зависимости которого
выключены, оно предлагает включить и их. Выбор сохраняется в `Mjolnir/Config/mod-list.json`.

Кнопка **Настройки** окна, в его нижней части, открывает собственные настройки Mjolnir: масштаб интерфейса меню и HUD
и клавишу консоли разработчика.

## Файлы, которые пишет Mjolnir {/* #files-mjolnir-writes */}

| Путь | Что |
|---|---|
| `Mjolnir/LogOutput.log` | Лог Mjolnir и каждого мода. Дописывается при каждом запуске |
| `Mjolnir/Config/<mod id>.toml` | Настройки каждого мода |
| `Mjolnir/Config/mjolnir.toml` | Собственные настройки Mjolnir |
| `Mjolnir/Config/mod-list.json` | Моды, которые вы выключили |
| `Mjolnir/interop/` | Сгенерированное представление кода игры для этой сборки игры |
| `Mjolnir/cache/` | Хеши файлов игры и лог генератора |

## Запуск один раз без модов {/* #start-once-without-mods */}

- Добавьте `--no-mods` в параметры запуска игры (Steam: **ASKA → Свойства → Параметры запуска**) или
- создайте пустой файл `Mjolnir/disable`.

Уберите параметр или файл, чтобы вернуть моды.

## Удаление {/* #uninstall */}

Удалите `version.dll` из папки игры. После этого игра запускается так, будто Mjolnir никогда не было. Удалите и папку
`Mjolnir/`, если моды, их настройки и лог больше не нужны.

:::note
Сетевая игра с модами проверена только при хостинге мира. Подключение к чужому миру с включёнными модами пока не
поддерживается.
:::
