# Установка

Mjolnir устанавливается в папку игры и не меняет ни одного файла игры. Удаляется он удалением одного файла.

## Установка {/* #install */}

1. Скачайте `Mjolnir-<version>.zip` со страницы
   [релизов](https://github.com/Aska-Modding-Community/Mjolnir/releases). Файл `.sha256` рядом с каждым архивом проверяет
   загрузку.
2. Распакуйте его в папку игры, ту, где лежит `Aska.exe`. В Steam: **ASKA → Управление → Просмотреть локальные файлы**.
   В архиве только `version.dll` и папка `Mjolnir/`.
3. Запустите игру из Steam как обычно.

При первом запуске Mjolnir генерирует C#-представление кода игры для вашей сборки игры: около полуминуты, под окном
прогресса. Затем игра запускается сама. Это повторяется после каждого обновления игры и каждого обновления Mjolnir;
остальные запуски этот шаг пропускают.

Кнопка окна прогресса останавливает генерацию и запускает игру без модов. Генерация снова выполнится при следующем
запуске.

## Добавление модов {/* #add-mods */}

Положите каждый мод в отдельную папку внутри `Mjolnir/Mods/`:

```text
ASKA/
├─ Aska.exe
├─ version.dll
└─ Mjolnir/
   └─ Mods/
      ├─ SomeMod/
      │  └─ SomeMod.dll
      └─ AnotherMod/
         ├─ AnotherMod.dll
         └─ lang/
```

Мод загружается после модов, которые ему нужны. Мод, зависимость которого отсутствует или имеет версию, которую он не
принимает, пропускается; окно модов объясняет почему.

## Окно модов {/* #the-mods-window */}

**Главное меню или меню паузы → Mjolnir** показывает установленные моды: имя, версию, автора и статус каждого. В каждой
строке есть:

- переключатель **Выкл / Вкл**, который действует со следующего запуска (заметка в нижней части окна говорит, что
  нужен перезапуск);
- кнопка **Настройки**, открывающая страницу настроек мода.

Перед выключением мода, который нужен другим, окно спрашивает. При включении мода с выключенными зависимостями оно
предлагает включить и их. Выбор сохраняется в `Mjolnir/Config/mod-list.json`.

Кнопка **Настройки** в нижней части окна открывает собственные настройки Mjolnir: масштаб интерфейса меню и HUD,
клавишу консоли разработчика и две опции для mod kit: модели персонажей игры и анимации игры (см.
[Mod kit](../guides/mod-kit.md#the-games-skeletons)).

## Файлы, которые пишет Mjolnir {/* #files-mjolnir-writes */}

| Путь | Что |
|---|---|
| `Mjolnir/LogOutput.log` | Лог Mjolnir и каждого мода, дописывается при каждом запуске |
| `Mjolnir/Config/<mod id>.toml` | Настройки каждого мода |
| `Mjolnir/Config/mjolnir.toml` | Собственные настройки Mjolnir |
| `Mjolnir/Config/mod-list.json` | Моды, которые вы выключили |
| `Mjolnir/interop/` | Сгенерированное представление кода игры для этой сборки игры |
| `Mjolnir/ModKit/` | Скелеты игры для [mod kit](../guides/mod-kit.md), а при включённых настройках набора — модели и клипы её людей. Только для этого компьютера |
| `Mjolnir/cache/` | Хеши файлов игры и лог генератора |

## Запуск один раз без модов {/* #start-once-without-mods */}

- Добавьте `--no-mods` в параметры запуска игры (Steam: **ASKA → Свойства → Параметры запуска**) или
- создайте пустой файл `Mjolnir/disable`.

Уберите параметр или файл, чтобы вернуть моды.

## Удаление {/* #uninstall */}

Удалите `version.dll` из папки игры: игра запускается так, будто Mjolnir никогда не было. Удалите и `Mjolnir/`, чтобы
убрать моды, их настройки и лог.

:::note
Чтобы зайти в чужой мир, включите те же моды, что у хоста, тех же версий. Иначе игра не пустит, а главное меню
перечислит, какие моды включить или выключить. Моды, которые меняют только вашу игру, например камеру или интерфейс,
не учитываются.
:::
