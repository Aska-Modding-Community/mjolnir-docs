# Mjolnir

Mjolnir — загрузчик модов и C# SDK для **ASKA** (Unity 6000.3, IL2CPP, HDRP). Моды собираются под .NET 10 и
работают на CoreCLR внутри процесса игры. SDK открывает игру как события C#, привязываемые значения и билдеры;
остальное — через HarmonyX.

:::note[Статус: 0.x]
Публичный API может меняться между минорными версиями; каждое изменение объявлено в файлах `PublicAPI.*.txt`
репозитория. Проверены: одиночная игра, хостинг мира и проверка модов между хостом и клиентом на двух машинах.
:::

## SDK {/* #the-sdk */}

Мод ссылается на основную библиотеку `Mjolnir.SDK` и только на нужные ему модули, каждый из которых — отдельная сборка.

| Сборка | Пространство имён | Что даёт |
|---|---|---|
| `Mjolnir.SDK` | `Mjolnir.SDK` | `Mod` и его жизненный цикл, манифесты и зависимости, конфиг в TOML, локализацию, привязываемые значения, `Dispatcher` главного потока, листы персонажей, аниматоры и участники боя, команды консоли |
| `Mjolnir.SDK.UI` | `Mjolnir.SDK.UI` | Окна, диалоги, элементы и метки HUD, уведомления, пункты меню, вкладки в собственных окнах игры, горячие клавиши, элементы управления, клонированные из интерфейса игры |
| `Mjolnir.SDK.Player` | `Mjolnir.SDK.Player` | Локальный игрок: появление и смерть, здоровье, выносливость, еда, вода, тепло, расход выносливости, положение и телепорт |
| `Mjolnir.SDK.Content` | `Mjolnir.SDK.Content` | Предметы, рецепты, постройки, эффекты состояния, модели предметов из AssetBundle, каталог предметов |
| `Mjolnir.SDK.Animation` | `Mjolnir.SDK.Animation` | Анимации и маски мода из его AssetBundle; связывает `CharacterAnimator` с игрой |
| `Mjolnir.SDK.Net` | `Mjolnir.SDK.Net` | Игроки сессии и каналы сообщений между их модами. Каждая сессия проверяет, что моды подключающегося игрока совпадают с модами хоста |
| `Mjolnir.SDK.AI` | `Mjolnir.SDK.AI` | Жители поселения и собственные работы мода |
| `Mjolnir.SDK.World` | `Mjolnir.SDK.World` | Часы мира |
| `Mjolnir.SDK.Stats` | (нет) | Подключает `CharacterSheet` к игре; публичных типов не имеет |
| `Mjolnir.SDK.Combat` | (нет) | Подключает `Combatant` и `Combatants` к игре: удары до и после попадания, смерти и их виновников; публичных типов не имеет |

Публичные сигнатуры модулей используют только типы .NET, Unity и TextMeshPro, никогда — типы игры. Переименование в
игре исправляется в SDK, и моды продолжают работать.

## Примеры {/* #examples */}

В `examples/` репозитория — готовые моды, по одной области на каждый:

| Мод | Показывает |
|---|---|
| `Mjolnir.InfiniteStamina` | Конфиг и чистые патчи Harmony |
| `Mjolnir.UiExample` | Все элементы управления UI, окно в стиле MVVM, уровни меню, вкладки в окнах игры, локализацию |
| `Mjolnir.PlayerExample` | Полосы HUD, привязанные к характеристикам игрока, более дешёвую выносливость |
| `Mjolnir.ItemsExample` | Предметы с собственными моделями, рецепты вручную и в мастерской, постройку, команду консоли |
| `Mjolnir.StatsExample` | Опыт и собственный эффект мода |
| `Mjolnir.VillagersExample` | Работу, которую берут жители |
| `Mjolnir.CheatInventory` | Каталог предметов в окне с поиском |
