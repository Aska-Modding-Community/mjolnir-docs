# Интерфейс

`Mjolnir.SDK.UI` строит интерфейс мода в коде из собственного интерфейса игры: её окна, строки настроек, кнопки, полосы
и слоты клонируются, так что мод выглядит как игра, ничего не рисуя сам. Он также даёт модам места в интерфейсе игры:
HUD, главное меню и меню паузы, меню настроек и журнал.

Подключите `Mjolnir.SDK.UI.dll` из `Mjolnir/core` и добавьте `using Mjolnir.SDK.UI;`.

## Как это работает {/* #how-it-works */}

Мод строит дерево **элементов**: элементов управления, таких как `UiButton`, и панелей, таких как `UiStackPanel`. Дерево —
источник истины. Когда оно показано, SDK делает его живые копии в Unity и держит их в согласии с ним при изменении
свойств.

- Элементы можно создавать и менять в любой момент, из любого потока, в том числе до запуска игры. То, что на экране,
  следует за ними на следующем кадре.
- Игра часто уничтожает и создаёт заново свой интерфейс (HUD с каждым миром, меню паузы, меню настроек при каждом
  открытии). SDK каждый раз строит копии заново из того же дерева.
- Картинкам и текстурам нужна запущенная игра. Окна с картинками стройте при первом использовании, а не в `OnLoad`.
- На выделенном сервере без графики любой вызов UI ничего не делает.

## Хосты {/* #hosts */}

Дерево элементов попадает на экран через хост:

| Хост | Что |
|---|---|
| `UiWindow` | Собственное окно мода, настоящее меню игры: освобождает курсор, блокирует ввод игрока, закрывается по Esc |
| `Hud.Add`, `Hud.AddAt` | HUD загруженного мира, в углу или над точкой мира |
| `Menus.Main.Add`, `Menus.Pause.Add` | Кнопки и пункты меню в главном меню и меню паузы |
| `Menus.Settings.Add`, `Menus.Journal.Add` | Собственные вкладки мода в меню настроек и журнале игры |
| `Dialog`, `Notify` | Диалоги и уведомления игры |

Обо всём, кроме окон, — в разделе [HUD, меню и уведомления](hud-and-menus.md).

## Окна {/* #windows */}

Унаследуйте класс от `UiWindow`, постройте элементы в конструкторе и задайте `Content`:

```csharp title="NotesWindow.cs"
using Mjolnir.SDK;
using Mjolnir.SDK.UI;

namespace NotesMod;

internal sealed class NotesWindow : UiWindow
{
    public NotesWindow()
    {
        Title = "Notes";
        Width = 720;
        Height = 480;

        var note = new UiTextBox { Header = "Note", PlaceholderText = "Write something", MaxLength = 120 };
        var save = new UiButton { Content = "Save" };
        save.Click += (_, _) => Notify.Message($"Saved: {note.Text}");

        Content = new UiStackPanel
        {
            Children =
            {
                new UiSectionHeader { Text = "Today" },
                note,
                save,
            },
        };

        Footer = new UiButton { Content = Localization.Get("common.close") }.OnClick(Close);
    }
}

[ModManifest("author.notes", "Notes", "1.0.0")]
public sealed class NotesMod : Mod
{
    private NotesWindow? _window;

    public override void OnLoad() =>
        Menus.Pause.Add(new UiButton { Content = "Notes" }).OnClick(() => (_window ??= new NotesWindow()).Show());
}
```

| Член | Что |
|---|---|
| `Show()`, `Close()`, `IsOpen` | Открыть и закрыть окно. Оно открыто, пока находится в стеке меню игры |
| `Opened`, `Closed` | Возникают при открытии и закрытии — кодом, по Esc или крестиком |
| `Title` | Заголовок на табличке в шапке окна |
| `Content` | Содержимое окна. Более высокое содержимое прокручивается |
| `Footer` | Полоса внизу, которая никогда не прокручивается, — для кнопок и заметок |
| `Width`, `Height` | Размер в опорных пикселях (см. «Размеры») |
| `MinWidth`, `MaxWidth`, `MinHeight`, `MaxHeight` | Пределы. Минимум побеждает максимум |
| `SizeToContent` | `Height` делает окно высотой с содержимое, в пределах его ограничений |
| `WindowStyle` | `Menu` или `Dialog`, задаётся до первого показа |
| `Dispose()` | Закрывает окно и уничтожает его объекты. До этого оно остаётся живым, и его привязки следуют за источниками |

### Стили {/* #styles */}

- **`WindowStyle.Menu`**, по умолчанию, — вид главных окон игры, таких как меню настроек и инвентарь: тёмная рамка с
  резными углами, крестик, размытый мир позади и заголовок на табличке на верхнем краю. Когда `Content` — это
  `UiTabControl` с вкладками сверху, вкладки занимают место таблички, как в меню настроек.
- **`WindowStyle.Dialog`** — вид диалогов и внутренних панелей игры: простая тёмная панель с заголовком внутри, без
  размытия.

### Размеры {/* #sizes */}

Размеры — опорные пиксели экрана 1920×1080, масштабируемые под реальный экран так же, как собственные меню игры. Сверх
того **масштаб интерфейса** игрока (в настройках Mjolnir, от 75 до 150 %) масштабирует каждое окно мода. Окно всегда
остаётся в пределах экрана, каковы бы ни были его размер и масштаб.

## Общее для элементов {/* #elements-in-common */}

Каждый элемент наследуется от `Control`:

| Свойство | Что |
|---|---|
| `Name` | Имя объекта Unity, чтобы найти его в иерархии |
| `IsVisible`, `IsEnabled` | Отключённый элемент отключает и затемняет всё, что в нём |
| `Width`, `Height`, `Min…`, `Max…` | Размеры. По умолчанию элементы растягиваются поперёк панели; элемент с собственным размером центрируется |
| `Margin`, `Padding` | Отступ снаружи и внутри, как `Thickness` |
| `HorizontalAlignment`, `VerticalAlignment` | Положение в месте, которое даёт панель |
| `FontSize` | Наследуется всем, что внутри, если там не задан свой |
| `Opacity` | От 0 до 1 |
| `ToolTip` | Строка показывает всплывающую карточку игры, её первая строка — заголовок; элемент показывается в карточке |
| `Loaded` | Возникает с `RectTransform` Unity, как только появилась живая копия |

Строки (`HeaderedControl`: текстовые поля, переключатели, ползунки, степперы, выпадающие списки, кнопки и текстовые
блоки) принимают также `Header` и `Description`. С заголовком элемент управления рисуется как одна из строк настроек
игры: название и описание слева, элемент управления справа. Без него это голый элемент управления. `Icon` ставит
картинку в левой части строки, а `ContentWidth` задаёт ширину её правой части.
