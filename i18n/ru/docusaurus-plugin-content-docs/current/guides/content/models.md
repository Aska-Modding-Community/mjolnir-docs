# Модели и набор мододела

Предмет мода может выглядеть по-своему: как префаб из AssetBundle, который мод поставляет с собой. Бандлы должны быть
собраны той же версией Unity, что и игра, **6000.3.12f1**, для Windows, с **HDRP**. Бандл, собранный другой Unity, в
игре не загружается.

## Набор мододела {/* #the-mod-kit */}

`unity/Mjolnir.ModKit` в репозитории — проект Unity, настроенный для этого: Unity 6000.3.12f1 с HDRP 17.3.0, тем же
конвейером рендеринга, что у игры.

1. Установите Unity **6000.3.12f1** через Unity Hub и откройте им `unity/Mjolnir.ModKit`. При открытии набор
   включает HDRP на всех уровнях качества (**Mjolnir → Set Up HDRP** делает это ещё раз).
2. Положите ассеты мода в `Assets/Mods/<mod>/<bundle>/`. Каждая такая папка — один бандл со всем, что в ней лежит.
3. **Mjolnir → Build Bundles** собирает каждый бандл в `Build/Bundles/<mod>/<bundle>`.
4. Скопируйте файл бандла в папку мода, например в `bundles/models`.

Скрипты в бандлы не попадают: игра не может выполнить `MonoBehaviour` мода из бандла.

При загрузке материалы берут собственный шейдер игры с тем же именем, поэтому используйте шейдеры игры по имени,
например `HDRP/Lit`. Опорная точка модели — начало координат предмета.

## Предмет с моделью {/* #an-item-with-a-model */}

```csharp
ModItem spool = Items.Add("twine_spool", basedOn: "Item_Materials_BasicRope", icon: "items/twine_spool.png")
                     .WithModel("bundles/models", "TwineSpool");
```

`WithModel(bundle, asset)` принимает файл бандла относительно папки мода и имя префаба в нём. В мире предмет остаётся
тем же, что и его основа: его поднимают, носят, бросают и передают по сети так же, как основу. Модель — только его
внешний вид:

- меши основы заменяются префабом;
- box-коллайдеры основы подгоняются под модель с тем же зазором, что они оставляли вокруг вида основы, так что она
  лежит на земле, дорожке или полке так же, как основа. Собственные коллайдеры префаба не используются;
- подсветка выбора в игре находит рендереры модели.

Модель, которая не загрузилась, пишется в лог, и предмет сохраняет вид своей основы.

```text
Mjolnir/Mods/TwineMod/
├─ TwineMod.dll
├─ items/twine_spool.png
└─ bundles/models
```

## Пакетная сборка {/* #batch-builds */}

`tools/build-bundles.ps1` в репозитории запускает набор в пакетном режиме и копирует бандлы примеров в
`examples/<mod>/bundles/`. Он находит Unity 6000.3.12f1 в папках установки Unity Hub; `-Unity <path>` или переменная
окружения `MJOLNIR_UNITY` указывают другое место. Unity блокирует открытый проект, поэтому сначала закройте редактор
или соберите из его меню и запустите скрипт с `-SkipBuild`.
