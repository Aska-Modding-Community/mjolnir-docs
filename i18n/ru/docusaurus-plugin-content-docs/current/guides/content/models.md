# Модели предметов

Предмет мода может использовать собственную модель — префаб из AssetBundle, который мод поставляет с собой и который
собран в [mod kit](../mod-kit.md) под версию Unity игры, **6000.3.12f1**, Windows и **HDRP**. Бандл, собранный другой
версией Unity, не загружается.

## Предмет с моделью {/* #an-item-with-a-model */}

```csharp
ModItem spool = Items.Add("twine_spool", basedOn: "Item_Materials_BasicRope", icon: "items/twine_spool.png")
                     .WithModel("bundles/models", "TwineSpool");
```

`WithModel(bundle, asset)` принимает файл бандла относительно папки мода и имя префаба в нём. В мире предмет ведёт
себя как основа: его так же поднимают, носят, бросают и передают по сети. Меняется только внешний вид:

- префаб заменяет меши основы;
- box-коллайдеры основы подгоняются под модель с тем же зазором, что был вокруг вида основы, так что она лежит на
  земле, дорожке или полке так же, как основа. Собственные коллайдеры префаба не используются;
- подсветка выбора в игре находит рендереры модели.

Модель, которая не загрузилась, пишется в лог, и предмет сохраняет вид своей основы.

```text
Mjolnir/Mods/TwineMod/
├─ TwineMod.dll
├─ items/twine_spool.png
└─ bundles/models
```

## Создание модели {/* #making-the-model */}

- Опорная точка модели — начало координат предмета.
- При загрузке материалы берут шейдер игры с тем же именем, поэтому используйте шейдеры игры по имени, например
  `HDRP/Lit`.
- Скрипты в бандлы не попадают: игра не может выполнить `MonoBehaviour` мода из бандла.
- **Mjolnir → Items → Render Item Icons** рисует выбранный префаб в картинку 256 × 256 для иконки предмета.

О сборке и копировании бандлов — в [Mod kit](../mod-kit.md), о модели постройки — в
[Постройках](buildings.md#look).
