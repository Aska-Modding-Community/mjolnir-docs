# Предметы и рецепты

`Mjolnir.SDK.Content` добавляет собственные предметы, рецепты, постройки и эффекты состояния мода. Подключите
`Mjolnir.SDK.Content.dll` и добавьте `using Mjolnir.SDK.Content;`. Всё здесь добавляется в `OnLoad`.

Ассеты игры называются по именам ассетов: `Item_Wood_Sticks`, `Item_Materials_BasicRope`,
`Item_Structures_WorkshopL0`. Их перечисляет команда консоли `items <words>`; см.
[Консоль разработчика](../console.md).

## Предметы {/* #items */}

Предмет делается из одного из предметов игры. Он сохраняет модель основы в мире, её вид, размер и звуки, а мод даёт ему
имя, картинку, размер стопки и тексты.

```csharp title="TwineMod.cs"
using Mjolnir.SDK;
using Mjolnir.SDK.Content;

namespace TwineMod;

[ModManifest("author.twine", "Twine", "1.0.0")]
public sealed class TwineMod : Mod
{
    public override void OnLoad()
    {
        ModItem twine = Items.Add("twine", basedOn: "Item_Materials_BasicRope", icon: "items/twine.png", stackSize: 20);

        // Две палки и верёвка дают две бечёвки, вручную и в мастерской, где делается верёвка.
        Recipes.Add(twine, quantity: 2)
               .Needs("Item_Wood_Sticks", 2)
               .Needs("Item_Materials_BasicRope", 1);

        // Катушка из пяти бечёвок и палки, только в мастерской.
        ModItem spool = Items.Add("twine_spool", basedOn: "Item_Materials_BasicRope", icon: "items/twine_spool.png", stackSize: 10);
        Recipes.Add(spool)
               .Needs(twine, 5)
               .Needs("Item_Wood_Sticks", 1)
               .MadeAt("Item_Structures_WorkshopL0");
    }
}
```

`Items.Add(name, basedOn, icon, stackSize)`:

- `name` — буквы, цифры и подчёркивания, уникально в пределах мода. Повторное добавление того же имени возвращает уже
  добавленный предмет; то же имя с другой основой выбрасывает исключение.
- `icon` — PNG или JPG относительно папки мода. Без него предмет показывает картинку основы.
- `stackSize` — сколько помещается в один слот. Без него — как у основы.

Тексты предмета берутся из файлов `lang` мода:

```toml title="lang/english.toml"
[item.twine]
name = "Twine"
description = "Thin cord twisted from rope fibres."
lore = "Coiled so it does not tangle."
```

Пропущенные описание или лор ничего не показывают. См. [Локализация](../../concepts/localization.md).

## Id и сохранения {/* #ids-and-saves */}

Id предмета — хеш id мода и имени предмета, всегда отрицательный, каким id игры не бывают никогда. Он одинаков на
каждой машине и при каждом запуске, какие бы другие моды ни были установлены. Его имя ассета —
`Item_<mod id>_<name>`.

Игра сохраняет предметы по id, поэтому сохранение с предметами мода загружает их обратно. Без мода игра молча
отбрасывает их, и следующее сохранение пишется уже без них. Никогда не переименовывайте предмет и не меняйте id мода
после релиза: id изменится, и сохранённые предметы пропадут.

## Рецепты {/* #recipes */}

`Recipes.Add(result, quantity, basedOn)` добавляет рецепт, который делает `quantity` штук предмета мода.
`Needs(item, count)` добавляет ингредиент, по имени ассета или как `ModItem`, в заданном порядке. Один рецепт на
результат; повторное добавление для того же предмета возвращает первый.

Рецепт делается из одного из рецептов игры, по умолчанию из рецепта верёвки (`Item_Binders_BasicRope`). Он берёт вид
и раздел меню этого рецепта и делается там, где делается этот рецепт: верёвка — вручную и в мастерской любого
уровня.

### Где делается рецепт {/* #where-a-recipe-is-made */}

`MadeAt(place)` заменяет места основы. Для каждого следующего места вызовите его ещё раз:

| Место | Значение |
|---|---|
| `ModRecipe.ByHand` | Крафт в меню строительства |
| имя ассета сооружения | Его столы крафта и столы каждого сооружения, до которого оно улучшается: `Item_Structures_WorkshopL0` покрывает все уровни мастерской. Подходит и пристройка, например `Item_Addons_Weaver` |

- Рецепт, который делается вручную, известен с самого начала: игрок новой игры начинает с ним, а игрок старого
  сохранения получает его при загрузке мира.
- Станция знает рецепты своих столов крафта, что бы ни знал игрок. Игрок крафтит их за её столом, а её жители делают
  их, когда их попросят.
- Станции берут рецепты, когда строятся или загружаются, поэтому места задавайте в `OnLoad`.

## Выдача предметов {/* #giving-items */}

```csharp
ModItem twine = Items.Add("twine", basedOn: "Item_Materials_BasicRope");   // тот же предмет, что выше

int given = Items.Give(twine, 10);              // предмет мода
int sticks = Items.Give("Item_Wood_Sticks", 5);  // предмет игры по имени ассета
```

`Give` возвращает, сколько попало в инвентарь локального игрока: 0 не в главном потоке, вне мира или без места.
`Items.CanGive` говорит, можно ли выдавать предметы сейчас.
