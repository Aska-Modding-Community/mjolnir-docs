# Оружие, броня и еда

`Items.Add(name, kind, icon, stackSize)` добавляет предмет определённого вида: оружие, часть брони, еду или материал.
Он опирается на простой предмет игры этого вида, так что моду не нужно имя предмета игры, и берёт его картинку, облик,
звуки и числа, пока мод не задаст свои.

```csharp title="EquipmentMod.cs"
using System;
using Mjolnir.SDK;
using Mjolnir.SDK.Content;

namespace EquipmentMod;

[ModManifest("author.equipment", "Equipment", "1.0.0")]
public sealed class EquipmentMod : Mod
{
    public override void OnLoad()
    {
        Items.Add("rune_sword", ItemKind.OneHandedWeapon, icon: "items/rune_sword.png")
             .WithDamage(14, 18)
             .WithDurability(800)
             .AppliesOnHit("Effect_Burning", TimeSpan.FromSeconds(4), chance: 0.25f);

        Items.Add("rune_hood", ItemKind.Helmet)
             .WithArmor(60)
             .WithAttribute("Attribute_ColdResistance", 50)
             .AppliesWhileEquipped("Effect_Energized");

        Items.Add("honey_cake", ItemKind.Food, stackSize: 5)
             .AppliesWhenEaten("Effect_Energized", TimeSpan.FromMinutes(2));
    }
}
```

Тексты, картинки, модели и рецепты работают как у любого [предмета](items-and-recipes.md). Для предмета, похожего на
конкретный предмет игры, например железный топор или длинный лук, используйте `Items.Add(name, basedOn: …)` — методы
ниже работают и с ним.

## Виды {/* #kinds */}

| `ItemKind` | Что это | Основа |
|---|---|---|
| `Material` | Небольшой материал для крафта, много в одной ячейке | Верёвка |
| `LargeMaterial` | Длинный или тяжёлый материал, который носят на спине | Доска |
| `Food` | Съедается из инвентаря | Ягоды |
| `OneHandedWeapon` | В правой руке, рядом можно держать щит | Железный меч |
| `TwoHandedWeapon` | В обеих руках | Двуручный железный меч |
| `Shield` | В левой руке | Грубый круглый щит |
| `Bow` | В обеих руках, стреляет стрелами | Простой лук |
| `Arrow` | В колчане | Деревянные стрелы |
| `Helmet`, `Chest`, `Pants`, `Boots`, `Gloves`, `Cape` | Надеваются | Тканевый комплект |

## Числа {/* #numbers */}

| Метод | Виды | Что |
|---|---|---|
| `WithDamage(minimum, maximum)` | Оружие, щиты, луки, стрелы | Урон удара до собственных расчётов игры: атаки, силы и навыка владельца, брони цели. Железный меч наносит 9–11, лук 3–6 |
| `WithArmor(armor)` | Любые | Броня тому, кто носит или держит предмет. Ткань не даёт ничего, кольчужная рубаха 400, латный шлем 160 |
| `WithDurability(durability)` | Любые | Сколько предмет служит. Железный меч 550, кольчужная рубаха 2800 |
| `WithAttribute(attribute, value)` | Любые | Атрибут игры по имени ассета, например `Attribute_ColdResistance`, `Attribute_RainProtection` или `Attribute_WindProtection`. Атрибуты надетого или удерживаемого предмета действуют на владельца. `0` убирает атрибут основы |

Остальные атрибуты основы сохраняются. Атрибут, которого нет в игре, пропускается с предупреждением в логе.

## Эффекты {/* #effects */}

| Метод | Виды | Что |
|---|---|---|
| `AppliesOnHit(effect, duration, chance)` | Одноручное и двуручное оружие, щиты | Удар может наложить эффект на цель с вероятностью `chance` от 0 до 1, как факел игры поджигает |
| `AppliesWhileEquipped(effect)` | Всё, что держат или носят | Эффект держится на том, кто держит или носит предмет, — на игроке или жителе — и уходит, когда предмет снимают. Оружие за спиной не считается |
| `AppliesWhenEaten(effect, duration)` | Еда | Эффект добавляется к тому, что даёт еда основы |

Эффект — эффект игры по имени ассета или собственный [`ModEffect`](effects.md) мода. Игра знает свои эффекты только
после запуска, поэтому предмет, добавленный в `OnLoad`, называет их по имени. Эффект, которого нет в игре,
пропускается с предупреждением в логе.

Метод для вида, который его не принимает, бросает `InvalidOperationException`; для предмета на основе названного
предмета игры он пишет предупреждение в лог.

## Пример {/* #example */}

`examples/Mjolnir.EquipmentExample` добавляет меч, капюшон и пирог из примера выше. Его команда консоли `equipment`
даёт игроку по одному каждого.
