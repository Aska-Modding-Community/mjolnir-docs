# Постройки

`Buildings.Add(name, basedOn, icon)` добавляет в меню строительства постройку, сделанную из одного из сооружений игры.
Её модель, размер, размещение, этапы строительства и назначение — от основы; мод даёт ей имя, id, картинку, тексты и,
с `Needs`, собственную стоимость.

```csharp
ModItem twine = Items.Add("twine", basedOn: "Item_Materials_BasicRope", icon: "items/twine.png");

Buildings.Add("twine_arch", basedOn: "Item_Decoration_ArchFlimsy", icon: "items/twine_arch.png")
         .Needs("Item_Wood_Sticks", 5)
         .Needs(twine, 4);
```

```toml title="lang/english.toml"
[building.twine_arch]
name = "Twine arch"
description = "Decoration"
lore = "Two posts and a bent top, bound with twine."
```

- `description` — строка под названием постройки в меню строительства, `lore` — текст ниже.
- Постройка стоит в меню строительства рядом со своей основой, и игрок знает её с самого начала, и в новой игре, и в
  старом сохранении.
- Возведённая постройка остаётся в сохранении по своему id: хешу id мода и `<name>`, одинаковому на каждой машине.
- Предметы и постройки мода делят имена: постройка не может взять имя одного из предметов мода.

## Стоимость {/* #cost */}

Без `Needs` постройка стоит столько же, сколько её основа. С `Needs` вся стоимость ложится на первый этап
строительства; остальным этапам ничего не нужно, их только строят.
