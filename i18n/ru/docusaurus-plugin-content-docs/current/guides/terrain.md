# Рельеф

`Mjolnir.SDK.Terrain` даёт модам землю мира: её высоту, её вид, её биом и воду над ней; изменения земли; деревья,
камни и кусты, которые на ней стоят; и поля выравнивания, которые разрабатывают жители. Подключите
`Mjolnir.SDK.Terrain.dll` и добавьте `using Mjolnir.SDK.Terrain;`.

Изменение делается так же, как его делает игра, — мотыгой игрока, лопатой жителя, площадкой постройки, — поэтому оно
применяется, сохраняется с миром, уходит к другим игрокам, убирает траву и позволяет жителям ходить по новой земле.
Оно остаётся в сохранении и без мода.

Для всего на этой странице действуют три ограничения:

- **Только загруженная часть мира** — 512 метров, которые игра подгружает вокруг игрока. За её пределами чтение
  ничего не даёт, а изменения отвечают `NotLoaded`.
- **Главный поток.** Из другого потока чтение ничего не даёт, а изменение делается в начале следующего кадра
  (`Queued`).
- **Одна машина.** В мультиплеере игра каждого игрока отправляет свои изменения остальным, и ничья игра их не
  проверяет, поэтому мод, меняющий землю на каждой машине, сделает изменение несколько раз. Меняйте её на одной
  машине — по умолчанию на машине хоста.

```csharp title="YardMod.cs"
using Mjolnir.SDK;
using Mjolnir.SDK.Player;
using Mjolnir.SDK.Terrain;
using Mjolnir.SDK.UI;
using UnityEngine;

namespace YardMod;

[ModManifest("author.yard", "Yard", "1.0.0")]
public sealed class YardMod : Mod
{
    private LandscapeOutline? _preview;
    private LandscapeSnapshot? _before;

    public override void OnGameReady()
    {
        HotKeys.Add(KeyGesture.Parse("F7"), TogglePreview);
        HotKeys.Add(KeyGesture.Parse("F8"), Flatten);
        HotKeys.Add(KeyGesture.Parse("F9"), Undo);

        // Готовый двор никто не раскопает.
        Landscape.GroundChanging += (_, e) =>
        {
            if (e.Source == LandscapeSource.Player && e.Operation == LandscapeOperation.Lower
                && _before is { } kept && e.Area.Overlaps(kept.Area.Bounds))
                e.Cancel = true;
        };
    }

    private static LandscapeArea Yard() => LandscapeArea.Circle(LocalPlayer.Position, radius: 6, blend: 2);

    private void TogglePreview()
    {
        if (_preview is { } shown)
        {
            shown.Dispose();
            _preview = null;
            return;
        }
        _preview = Landscape.ShowOutline(Yard(), Color.yellow);
    }

    private void Flatten()
    {
        LandscapeArea yard = Yard();
        LandscapeHeights heights = Landscape.Measure(yard);
        if (!heights.IsKnown) return;

        _before = Landscape.Capture(yard);        // собственная отмена мода
        LandscapeResult result = Landscape.Level(yard, heights.Average, new LandscapeOptions
        {
            Kind = GroundKind.Path,               // тропа, а не голая земля игры
            Objects = LandscapeObjects.Settle,    // деревья остаются и встают на новую землю
        });
        Notify.Message(result == LandscapeResult.Done
            ? $"Двор выровнен на {heights.Average:0.##} м"
            : $"Здесь двора не будет: {result}");
    }

    private void Undo()
    {
        if (_before is not { } kept) return;
        kept.Restore();
        _before = null;
    }
}
```

## Чтение земли {/* #reading-the-ground */}

| `Landscape` | Что |
|---|---|
| `IsAvailable` | Загружен ли мир. `false` в главном меню |
| `IsLoaded(x, z)` | Находится ли точка в загруженной части мира, то есть можно ли читать и менять её землю |
| `HeightAt(x, z)` | Высота земли в метрах; `NaN`, где она неизвестна |
| `TryGetHeight(x, z, out height)` | То же самое, с ответом, известна ли она |
| `NormalAt(x, z)` | Куда обращена земля, длина 1; `(0, 0, 0)`, где это неизвестно |
| `KindAt(x, z)` | Какая там земля |
| `IsCleared(x, z)` | Убраны ли там трава и кусты изменением земли |
| `WaterLevel`, `IsUnderwater(x, z)` | Высота моря (в мире оно одно) и находится ли земля под ним |
| `Measure(area)` | Самая низкая, самая высокая и средняя высота области, через каждые полметра |

Высоты — мировые, в метрах, от 0 до `Landscape.MaximumHeight` (160).

### Какая бывает земля {/* #what-the-ground-is */}

Игра хранит вид земли для каждого полуметра мира:

| `GroundKind` | Что |
|---|---|
| `Natural` | Какой мир был создан: трава, мох, камень, песок — что растёт в этом месте |
| `Dirt` | Голая земля: такой она становится там, где её копали, поднимали или выравнивали |
| `Bedrock` | Скала под землёй |
| `Path` | Тропа, какой её прокладывает дорожник |
| `Road` | Дорога, какой её прокладывает план дороги |

## Области {/* #areas */}

Изменение идёт по `LandscapeArea` — фигуре на земле, край которой плавно переходит в землю вокруг. Учитываются только
x и z точки.

| Область | Что |
|---|---|
| `LandscapeArea.Rectangle(center, width, depth, rotation, blend, falloff)` | Прямоугольник, повёрнутый вокруг своей середины на градусы |
| `LandscapeArea.Circle(center, radius, blend, falloff)` | Круг |
| `LandscapeArea.Polygon(points, blend, falloff)` | Многоугольник по 3–256 углам в порядке обхода, последний соединяется с первым |
| `LandscapeArea.Mask(center, weights, width, depth, rotation)` | Собственная маска мода: `float[,]` весов от 0 до 1, строки по z и столбцы по x, разложенные на заданные метры и повёрнутые |
| `LandscapeArea.Point(center, brush)` | Одна из кистей игры в точке, как ими работают её инструменты |

Стороны — не больше `MaximumSide` (64 м), плавный край — не больше `MaximumBlend` (16 м), маска — не больше
`MaximumMaskSamples` (1024) отсчётов по стороне. Область за этими пределами бросает `ArgumentOutOfRangeException`.
`Bounds` — прямоугольник, который область задевает, вместе с её плавным краем и поворотом: x — это x мира, y — z мира.

Поднятие, копание, выравнивание, покраску и очистку прямоугольника и кисти делает собственный инструмент игры, с её
собственным краем. Любую другую область и любое другое изменение SDK пишет сам, отсчёт за отсчётом — через каждые
полметра, каждый отсчёт сдвигается настолько, насколько велик вес области в этом месте: 1 внутри фигуры, падает по
плавному краю, 0 снаружи.

| `LandscapeFalloff` | Как изменение, записанное SDK, затухает по плавному краю |
|---|---|
| `Smooth` | Мягко с обоих концов края, круче всего в его середине: ни одного залома там, где изменение встречается с землёй |
| `Linear` | Равномерно по краю: прямой откос |

| `LandscapeBrush` | Что |
|---|---|
| `Small` | Около 2,5 м в поперечнике: копок мотыгой |
| `Medium` | Около 3,5 м, с жёстким краем: выравнивание мотыгой |
| `Soft` | Около 3,5 м, с мягким краем: лопата или дорожник |
| `Large` | Самая большая кисть игры |

## Изменение земли {/* #changing-the-ground */}

Каждое изменение отвечает `LandscapeResult` и принимает `LandscapeOptions`.

| `Landscape` | Что |
|---|---|
| `Raise(area, height, options)` | Земля поднимается на заданные метры, не больше `MaximumStep` (10 м) за раз |
| `Lower(area, depth, options)` | Земля выкапывается вниз, так же |
| `Level(area, height, options)` | Земля приводится к одной мировой высоте, её край переходит в землю вокруг |
| `Paint(area, kind, options)` | Вид земли меняется; её высота остаётся |
| `ClearVegetation(area, options)` | Трава, кусты и саженцы уходят, как их убирают грабли игры |
| `RestoreVegetation(area, options)` | Земля снова становится `Natural` и перестаёт быть помеченной как очищенная, так что трава её биома тут же вырастает снова. Высота остаётся, а кусты, забранные изменением, не возвращаются |
| `Smooth(area, strength, options)` | Каждая точка сдвигается к средней высоте земли примерно в метре вокруг неё, на `strength` (от 0 до 1). Повторённое, сглаживает дальше |
| `Slope(area, from, to, options)` | Пандус между высотами двух точек: каждая точка берёт высоту линии между ними там, где лежит напротив неё |
| `Shape(area, height, options)` | Высоты, которые даёт функция мода: её спрашивают для каждой точки со смещением от середины области по x и z и текущей высотой, а она отвечает нужной высотой (`NaN` оставляет точку как есть) |
| `Check(area, operation)` | Что ответило бы изменение, не делая его |

```csharp
// Воронка 8 м в поперечнике: глубже всего в середине, её край остаётся как был.
var area = LandscapeArea.Circle(center, radius: 4, blend: 1.5f);
Landscape.Shape(area, (dx, dz, now) =>
{
    float r = Mathf.Sqrt(dx * dx + dz * dz) / 4f;
    return now - 2.5f * (1f - r * r);
});
```

| `LandscapeResult` | Что |
|---|---|
| `Done` | Земля изменилась; это видно через кадр-другой |
| `Queued` | Запрошено из другого потока: будет сделано в главном потоке в начале следующего кадра |
| `NotAvailable` | Мир не загружен |
| `NotLoaded` | Область не целиком в загруженной части мира |
| `Blocked` | В области стоит постройка, или игра не меняет там землю |
| `TooSteep` | Земля там слишком крутая для игры |
| `TooHigh` | Земля поднялась бы выше, чем позволяет игра |
| `Underwater` | Область под водой |
| `Cancelled` | Обработчик `GroundChanging` отменил изменение |
| `Failed` | Игра не смогла сделать изменение; причина в логе |

### Параметры {/* #options */}

| `LandscapeOptions` | Что |
|---|---|
| `Kind` | Каким становится вид земли там, где меняется её высота; `null` — как в игре, `Dirt` |
| `KeepKind` | Земля вместо этого сохраняет свой вид: луг остаётся лугом, дорога дорогой. С `ClearVegetation` равным false остаётся и трава — для мягкого сглаживания природного склона, для холма посреди луга |
| `ClearVegetation` | Уходят ли трава, кусты и саженцы в области. Игра убирает их при любом изменении высоты; изменение вида земли их сохраняет |
| `OnlyOn` | Единственный вид земли, которого касается изменение: с `Natural` поднятие, сглаживание или биом оставляют дороги, тропы и перекопанную землю в области как есть |
| `Objects` | Что происходит с естественными объектами, стоящими там, где меняется земля |
| `KeepOffBuildings` | Отказывает ли изменение (`Blocked`), когда в области стоит постройка. Собственная проверка игры постройки не смотрит; SDK смотрит, если это не выключено |
| `UpdateNavigation` | Пересчитываются ли пути жителей и существ для новой земли, как это делает игра |

У каждого параметра по умолчанию поведение самой игры; `LandscapeOptions.Default` — то, с чем идёт изменение без
параметров. Изменение, ограниченное `OnlyOn` или сохраняющее свои объекты, всегда пишет SDK, какой бы ни была область.

:::warning[Одно изменение одной земли за кадр]
Поднятие, копание, выравнивание, покраску и очистку прямоугольника или кисти игра применяет позже в том же кадре.
Второе изменение той же земли в этом кадре прочитает землю такой, какой она была до первого, и запишет её обратно:
дорога, покрашенная и затем поднятая с `OnlyOn` в одном кадре, поднимется вместе со всем остальным. Делайте следующее
изменение кадром позже — в следующем `OnUpdate` или через `Dispatcher.MainThread.Post`.
:::

## Снимки {/* #snapshots */}

`Landscape.Capture(area)` сохраняет землю области такой, какая она сейчас, через каждые полметра: её высоты, её вид, её
растительность и её биом. Снимок живёт в памяти мода, а не в сохранении, и объекты мира в него не входят.

| `LandscapeSnapshot` | Что |
|---|---|
| `Area`, `CenterHeight` | Что сохранено и какой была высота земли в середине области |
| `HeightAt(x, z)` | Сохранённая высота в точке; `NaN` за пределами сохранённого |
| `Restore(options)` | Возвращает землю точно такой, какой она была сохранена, везде, куда достаёт область: отмена |
| `PasteAt(center, rotation, heightOffset, options)` | Укладывает ту же землю в другом месте, повёрнутой и поднятой или опущенной. Её высоты переходят в землю по весу области; там, где область хотя бы наполовину, с ними переносятся её вид и растительность, а биом у места остаётся свой |

Передайте `heightOffset: Landscape.HeightAt(x, z) - snapshot.CenterHeight`, чтобы уложить сохранённую землю
относительно земли на новом месте. Возврат газона 28 м из 613 точек занял в игре 19 мс, и ни вид, ни пометка, ни биом
не разошлись.

## Биом {/* #the-biome */}

Биом — это то, что растёт на земле (деревья, кусты и трава), и то, как она выглядит. Игра хранит по одному биому на
каждые `Landscape.BiomeCellSize` (4 м) мира.

Биом — это номер, а не название: каждая часть мира растит на нём свои растения, поэтому один и тот же номер — это
берёзовый лес в Зелёных землях и кипарисовый в болотах. Поэтому `LandscapeBiome.Name` — название того, что растёт на
нём в той части мира, где находится игрок, а два биома равны по одному `Id`.

| `Landscape` | Что |
|---|---|
| `Biomes` | Биомы, на которых часть мира, где находится игрок, растит свои растения, в порядке игры |
| `BiomeAt(x, z)` | Биом земли в точке; `null`, где он неизвестен |
| `FindBiome(name)` | Один из `Biomes` по названию в любом регистре (`"BirchForest"`); `null`, если такого нет |
| `PaintBiome(area, biome, options)` | Делает его биомом земли, так что растущее там тут же меняется на него |

```csharp
// Вырастить вокруг поселения берёзовый лес, только на природной земле.
if (Landscape.FindBiome("BirchForest") is { } birches)
    Landscape.PaintBiome(LandscapeArea.Circle(center, 24), birches,
        new LandscapeOptions { OnlyOn = GroundKind.Natural });
```

Клетка берёт новый биом там, где её середина лежит в области, а вес области в этом месте не меньше половины, так что
область меньше клетки может не изменить ни одной, а плавный край лишь расширяет её. Высота земли, её вид и пометка
убранной травы остаются, и стоящие там деревья, кусты и камни тоже остаются. Покраска 10 × 10 м заняла в игре 6 мс.

## Контур области {/* #an-areas-outline */}

`Landscape.ShowOutline(area, color)` рисует область на земле, следуя её высотам: предпросмотр того, куда пойдёт
изменение, или кисть под курсором. Контур рисуется только на этой машине, ни в одно сохранение не попадает и скрыт,
пока мир не загружен.

| `LandscapeOutline` | Что |
|---|---|
| `Area` | Обведённая область; её замена переносит контур |
| `Color` | Цвет линии |
| `IsVisible` | Показан ли он; скрытый контур сохраняет свою область и цвет |
| `Dispose()` | Убирает его с земли окончательно |

Край области — одна линия, внешний край плавного края прямоугольника или круга — вторая, тоньше. Свойства можно
задавать из любого потока, они применяются в следующем кадре. Контур уходит, когда его освобождают или когда его мод
отключается после ошибки.

## События {/* #events */}

```csharp
Landscape.GroundChanging += (_, e) =>
{
    // Жителям нельзя копать в роще.
    if (e.Source == LandscapeSource.Resident && e.Area.Overlaps(grove)) e.Cancel = true;
};

Landscape.GroundChanged += (_, e) => Log.Info($"{e.Operation} в {e.Area} от {e.Source}");
```

`GroundChanging` вызывается на этой машине перед изменением земли, кем бы оно ни делалось: инструментом игрока,
жителем, постройкой, модом или игрой. Обработчик может его отменить, и игра тогда отвечает так же, как на отказ
поставить что-то. `GroundChanged` вызывается после того, как земля изменилась, здесь или на машине другого игрока,
когда её новые высоты уже видны.

| Аргументы обоих событий | Что |
|---|---|
| `Area` | Земля, которую изменение задевает, примерно: x — это x мира, y — z мира |
| `Operation` | Что делается. `null` в `GroundChanged` для изменения, пришедшего по сети |
| `Source` | Кто его делает |
| `ModId` | Мод, который делает его через `Landscape`, или `null`, когда это игра |

У `LandscapeChangedEventArgs` есть ещё `IsRemote` — true для изменения с машины другого игрока. Изменения, пришедшие
по сети, сообщает только `GroundChanged`: игра, которая их сделала, вызвала `GroundChanging` у себя. Выравнивание по
плану дороги тоже сообщает только `GroundChanged`.

| `LandscapeSource` | Кто |
|---|---|
| `Player` | Игрок с инструментом в руках |
| `Resident` | Житель на работе |
| `Building` | Постройка: выровненная площадка под ней, вспаханное поле, план выравнивания или дороги в работе |
| `Mod` | Мод, через `Landscape`; `ModId` говорит, какой |
| `Remote` | Игра другого игрока, по сети (только `GroundChanged`) |
| `Other` | Что-то ещё в игре |

| `LandscapeOperation` | Что |
|---|---|
| `Raise`, `Lower`, `Level` | Земля идёт вверх, вниз или к одной высоте |
| `Paint` | Её вид меняется; её высота остаётся |
| `ClearVegetation`, `RestoreVegetation` | Её трава и кусты уходят или её собственный вид и трава возвращаются |
| `Smooth`, `Slope`, `Shape` | Сглажена, сделана пандусом или получила собственные высоты мода |
| `Restore`, `Paste` | Снимок возвращён или уложен в другом месте |
| `PaintBiome` | Её биом меняется, а с ним и то, что там растёт |

## Объекты мира {/* #the-worlds-objects */}

`NaturalObjects` даёт деревья, камни, кусты, гнёзда и грибы, которые вырастил мир, и предметы, лежащие на земле, —
ближайшие первыми.

| `NaturalObjects` | Что |
|---|---|
| `In(area)` | Все объекты, место которых хотя бы наполовину в области |
| `Around(center, radius)` | В пределах заданных метров, не больше `MaximumRadius` (64 м) |
| `Nearest(center, radius)` | Ближайший или `null` |

| `NaturalObject` | Что |
|---|---|
| `AssetName` | Название в игре того, что это (`"Harvest_Wood_birch1"`) |
| `Kind` | Какого рода эта вещь |
| `ResourceName` | Название в игре предмета, который даёт сбор (`"Item_Wood_birch1"`), или `""` |
| `Position`, `HeightOverGround` | Где он стоит и насколько выше или ниже земли под ним |
| `Health`, `Quantity` | Сколько от него осталось, как игра считает это для дерева или залежи, и сколько осталось его ресурса |
| `IsRemovable` | Забирает ли его изменение земли: куст или небольшой камень — да, дерево или валун — нет |
| `IsHarvestable`, `GatherCount` | Может ли игрок собрать или срубить его и сколько предметов ещё можно собрать руками |
| `IsGone` | Нет ли его больше в мире. Спрашивайте объекты заново, а не держите один надолго |
| `Gather(charges)` | Собирает с него так же, как игрок руками: предметы падают на землю рядом, его количество уменьшается, а игра сообщает об этом другим игрокам. Отвечает, сколько предметов он дал |
| `Remove()` | Убирает его из мира так же, как это делает изменение земли. Дерево или валун остаётся |
| `Settle()` | Ставит его на землю под ним, чтобы дерево, оставшееся в воздухе после изменения, снова стояло на ней |
| `MoveTo(position)` | Переносит его куда угодно вместе с видимой моделью. Собственные проверки игры о том, где вещь может стоять, не делаются |

Дерево рубят инструментом, а не собирают руками, поэтому `GatherCount` и `Gather` отвечают для него 0. `Settle` и
`MoveTo` по сети не уходят: другие игроки видят объект там, где он стоял, пока не загрузят эту часть мира снова.

| `NaturalObjectKind` | Что |
|---|---|
| `Grass` | Трава и подобное, рисуемое тысячами: отдельного объекта в мире нет |
| `Plant` | Растение: лён, куст с ягодами, гриб |
| `Tree` | Дерево |
| `Object` | Вещь мира: небольшой камень, гнездо, бревно |
| `LargeObject` | Большая вещь: валун, скальный камень, залежь руды |
| `Item` | Предмет, лежащий в мире: выброшенный игроком или посаженный в землю саженец |
| `Other` | Что-то ещё или то, о чём игра не говорит |

`LandscapeOptions.Objects` говорит, что изменение земли с ними делает:

| `LandscapeObjects` | Что |
|---|---|
| `Remove` | Как в игре: кусты, саженцы и небольшие камни, которые забирает изменение, забираются |
| `Keep` | Ничего не забирается: объекты остаются там, где стояли, теперь над или под новой землёй |
| `Settle` | Ничего не забирается: каждый объект области ставится на новую землю под ним |

## Поля выравнивания {/* #levelling-fields */}

Поле выравнивания — это план, который игрок ставит, чтобы жители выровняли землю по плиткам до одной высоты. Мод
ставит такой же и может выровнять его сразу, не дожидаясь жителей. Игра сохраняет поле и отправляет его другим
игрокам.

| `LevellingFields` | Что |
|---|---|
| `All` | Поля выравнивания загруженного мира |
| `Nearest(center, radius)` | Поле, ближайшее к точке, или `null` |
| `Place(area)` | Ставит поле по области: сетку из целых плиток по `TileSize` (2 м), уложенную по осям мира и подогнанную к середине области. Не больше `MaximumTiles` (256) — столько позволяет собственный план игры |

Поворот области не используется, а её плавный край не считается: сетку задают собственные стороны области,
округлённые до целых плиток.

| `LevellingField` | Что |
|---|---|
| `Center`, `Width`, `Depth` | Где поле и насколько велико, в метрах |
| `Tiles`, `LevelledTiles`, `IsLevelled` | Сколько у него плиток, сколько выровнено и выровнены ли все |
| `Height`, `HeightDifference` | Высота, к которой идут его плитки, и насколько его земля ещё отстоит от неё в худшем месте |
| `IsGone` | Нет ли плана больше в мире: закончен, убран или вне загруженной части |
| `LevelNow()` | Выравнивает все оставшиеся плитки так же, как жители выравнивают их мотыгами. Отвечает, сколько выровнено теперь |
| `Finish()` | Превращает план в то, что он строит, как делает игра, когда план выровнен. Простое поле выравнивания ничего не строит, поэтому оно просто уходит |
| `Remove()` | Убирает план так же, как игрок его разбирает, оставляя землю как есть |

Игра сама заканчивает план, у которого выровнена последняя плитка, поэтому сразу после того, как `LevelNow()`
выровнял все, поле уже `IsGone` и заканчивать (`Finish`) нечего. `HeightDifference` считается по отрисованной земле,
поэтому после `LevelNow()` оно обновляется только в следующем кадре.

:::note[Ещё не сделано]
- Проверено в одиночной игре и в мире с хостом; что видит изменения мода подключившийся клиент, ещё не проверено.
- Рубка дерева с его добычей. Мод может собрать (`Gather`) то, что игрок берёт руками, и убрать (`Remove`) то, что
  забирает изменение земли, но нанести удар инструментом за него нельзя.
- Выращивание собственного дерева, камня или куста: объекты мира можно читать, переносить и убирать, но не добавлять.
- Вода: её уровень можно прочитать, но не изменить.
:::
