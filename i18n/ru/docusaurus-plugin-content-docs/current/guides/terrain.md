# Рельеф

`Mjolnir.SDK.Terrain` даёт модам землю мира: её высоту, её вид, её биом и воду над ней; изменения земли; деревья,
камни и кусты, которые на ней стоят; поля выравнивания, которые разрабатывают жители; и пруды. Подключите
`Mjolnir.SDK.Terrain.dll` и добавьте `using Mjolnir.SDK.Terrain;`.

Изменение делается так же, как его делает игра, — мотыгой игрока, лопатой жителя, площадкой постройки, — поэтому оно
применяется, сохраняется с миром, уходит к другим игрокам, убирает траву и позволяет жителям ходить по новой земле.
Оно остаётся в сохранении и без мода.

Для всего на этой странице действуют три ограничения:

- **Только загруженная часть мира** — 512 метров, которые игра подгружает вокруг игрока. За её пределами чтение
  ничего не даёт, а изменения отвечают `NotLoaded`.
- **Главный поток.** Из другого потока чтение ничего не даёт, а изменение делается в начале следующего кадра
  (`Queued`).
- **Одна машина.** В мультиплеере игра каждого игрока отправляет свои изменения остальным, и ничья игра их не
  проверяет, поэтому мод, меняющий землю на каждой машине, сделает изменение несколько раз. Меняйте её на одной
  машине — по умолчанию на машине хоста.

```csharp title="YardMod.cs"
using Mjolnir.SDK;
using Mjolnir.SDK.Player;
using Mjolnir.SDK.Terrain;
using Mjolnir.SDK.UI;
using UnityEngine;

namespace YardMod;

[ModManifest("author.yard", "Yard", "1.0.0")]
public sealed class YardMod : Mod
{
    private LandscapeOutline? _preview;
    private LandscapeSnapshot? _before;

    public override void OnGameReady()
    {
        HotKeys.Add(KeyGesture.Parse("F7"), TogglePreview);
        HotKeys.Add(KeyGesture.Parse("F8"), Flatten);
        HotKeys.Add(KeyGesture.Parse("F9"), Undo);

        // Готовый двор никто не раскопает.
        Landscape.GroundChanging += (_, e) =>
        {
            if (e.Source == LandscapeSource.Player && e.Operation == LandscapeOperation.Lower
                && _before is { } kept && e.Area.Overlaps(kept.Area.Bounds))
                e.Cancel = true;
        };
    }

    private static LandscapeArea Yard() => LandscapeArea.Circle(LocalPlayer.Position, radius: 6, blend: 2);

    private void TogglePreview()
    {
        if (_preview is { } shown)
        {
            shown.Dispose();
            _preview = null;
            return;
        }
        _preview = Landscape.ShowOutline(Yard(), Color.yellow);
    }

    private void Flatten()
    {
        LandscapeArea yard = Yard();
        LandscapeHeights heights = Landscape.Measure(yard);
        if (!heights.IsKnown) return;

        _before = Landscape.Capture(yard);        // собственная отмена мода
        LandscapeResult result = Landscape.Level(yard, heights.Average, new LandscapeOptions
        {
            Kind = GroundKind.Path,               // тропа, а не голая земля игры
            Objects = LandscapeObjects.Settle,    // деревья остаются и встают на новую землю
        });
        Notify.Message(result == LandscapeResult.Done
            ? $"Двор выровнен на {heights.Average:0.##} м"
            : $"Здесь двора не будет: {result}");
    }

    private void Undo()
    {
        if (_before is not { } kept) return;
        kept.Restore();
        _before = null;
    }
}
```

## Чтение земли {/* #reading-the-ground */}

| `Landscape` | Что |
|---|---|
| `IsAvailable` | Загружен ли мир. `false` в главном меню |
| `IsLoaded(x, z)` | Находится ли точка в загруженной части мира, то есть можно ли читать и менять её землю |
| `HeightAt(x, z)` | Высота земли в метрах; `NaN`, где она неизвестна |
| `TryGetHeight(x, z, out height)` | То же самое, с ответом, известна ли она |
| `NormalAt(x, z)` | Куда обращена земля, длина 1; `(0, 0, 0)`, где это неизвестно |
| `KindAt(x, z)` | Какая там земля |
| `IsCleared(x, z)` | Убраны ли там трава и кусты изменением земли |
| `WaterLevel`, `IsUnderwater(x, z)` | Высота моря (в мире оно одно) и находится ли земля под ним |
| `Measure(area)` | Самая низкая, самая высокая и средняя высота области, через каждые полметра |

Высоты — мировые, в метрах, от 0 до `Landscape.MaximumHeight` (160).

### Какая бывает земля {/* #what-the-ground-is */}

Игра хранит вид земли для каждого полуметра мира:

| `GroundKind` | Что |
|---|---|
| `Natural` | Какой мир был создан: трава, мох, камень, песок — что растёт в этом месте |
| `Dirt` | Голая земля: такой она становится там, где её копали, поднимали или выравнивали |
| `Bedrock` | Скала под землёй |
| `Path` | Тропа, какой её прокладывает дорожник |
| `Road` | Дорога, какой её прокладывает план дороги |

## Области {/* #areas */}

Изменение идёт по `LandscapeArea` — фигуре на земле, край которой плавно переходит в землю вокруг. Учитываются только
x и z точки.

| Область | Что |
|---|---|
| `LandscapeArea.Rectangle(center, width, depth, rotation, blend, falloff)` | Прямоугольник, повёрнутый вокруг своей середины на градусы |
| `LandscapeArea.Circle(center, radius, blend, falloff)` | Круг |
| `LandscapeArea.Polygon(points, blend, falloff)` | Многоугольник по 3–256 углам в порядке обхода, последний соединяется с первым |
| `LandscapeArea.Mask(center, weights, width, depth, rotation)` | Собственная маска мода: `float[,]` весов от 0 до 1, строки по z и столбцы по x, разложенные на заданные метры и повёрнутые |
| `LandscapeArea.Point(center, brush)` | Одна из кистей игры в точке, как ими работают её инструменты |

Стороны — не больше `MaximumSide` (64 м), плавный край — не больше `MaximumBlend` (16 м), маска — не больше
`MaximumMaskSamples` (1024) отсчётов по стороне. Область за этими пределами бросает `ArgumentOutOfRangeException`.
`Bounds` — прямоугольник, который область задевает, вместе с её плавным краем и поворотом: x — это x мира, y — z мира.

Поднятие, копание, выравнивание, покраску и очистку прямоугольника и кисти делает собственный инструмент игры, с её
собственным краем. Любую другую область и любое другое изменение SDK пишет сам, отсчёт за отсчётом — через каждые
полметра, каждый отсчёт сдвигается настолько, насколько велик вес области в этом месте: 1 внутри фигуры, падает по
плавному краю, 0 снаружи.

| `LandscapeFalloff` | Как изменение, записанное SDK, затухает по плавному краю |
|---|---|
| `Smooth` | Мягко с обоих концов края, круче всего в его середине: ни одного залома там, где изменение встречается с землёй |
| `Linear` | Равномерно по краю: прямой откос |

| `LandscapeBrush` | Что |
|---|---|
| `Small` | Около 2,5 м в поперечнике: копок мотыгой |
| `Medium` | Около 3,5 м, с жёстким краем: выравнивание мотыгой |
| `Soft` | Около 3,5 м, с мягким краем: лопата или дорожник |
| `Large` | Самая большая кисть игры |

## Изменение земли {/* #changing-the-ground */}

Каждое изменение отвечает `LandscapeResult` и принимает `LandscapeOptions`.

| `Landscape` | Что |
|---|---|
| `Raise(area, height, options)` | Земля поднимается на заданные метры, не больше `MaximumStep` (10 м) за раз |
| `Lower(area, depth, options)` | Земля выкапывается вниз, так же |
| `Level(area, height, options)` | Земля приводится к одной мировой высоте, её край переходит в землю вокруг |
| `Paint(area, kind, options)` | Вид земли меняется; её высота остаётся |
| `ClearVegetation(area, options)` | Трава, кусты и саженцы уходят, как их убирают грабли игры |
| `RestoreVegetation(area, options)` | Земля снова становится `Natural` и перестаёт быть помеченной как очищенная, так что трава её биома тут же вырастает снова. Высота остаётся, а кусты, забранные изменением, не возвращаются |
| `Smooth(area, strength, options)` | Каждая точка сдвигается к средней высоте земли примерно в метре вокруг неё, на `strength` (от 0 до 1). Повторённое, сглаживает дальше |
| `Slope(area, from, to, options)` | Пандус между высотами двух точек: каждая точка берёт высоту линии между ними там, где лежит напротив неё |
| `Shape(area, height, options)` | Высоты, которые даёт функция мода: её спрашивают для каждой точки со смещением от середины области по x и z и текущей высотой, а она отвечает нужной высотой (`NaN` оставляет точку как есть) |
| `Check(area, operation)` | Что ответило бы изменение, не делая его |

```csharp
// Воронка 8 м в поперечнике: глубже всего в середине, её край остаётся как был.
var area = LandscapeArea.Circle(center, radius: 4, blend: 1.5f);
Landscape.Shape(area, (dx, dz, now) =>
{
    float r = Mathf.Sqrt(dx * dx + dz * dz) / 4f;
    return now - 2.5f * (1f - r * r);
});
```

| `LandscapeResult` | Что |
|---|---|
| `Done` | Земля изменилась; это видно через кадр-другой |
| `Queued` | Запрошено из другого потока: будет сделано в главном потоке в начале следующего кадра |
| `NotAvailable` | Мир не загружен |
| `NotLoaded` | Область не целиком в загруженной части мира |
| `Blocked` | В области стоит постройка, неподвижное место мира или запретная зона другого мода, либо игра не меняет там землю |
| `Partial` | Сделано в обход того, что стоит в области, или с подгонкой земли под ним (`ObstacleMode`), а остальное изменено |
| `TooSteep` | Земля там слишком крутая для игры |
| `TooHigh` | Земля поднялась бы выше, чем позволяет игра |
| `Underwater` | Область под водой |
| `Cancelled` | Обработчик `GroundChanging` отменил изменение |
| `Failed` | Игра не смогла сделать изменение; причина в логе |

### Параметры {/* #options */}

| `LandscapeOptions` | Что |
|---|---|
| `Kind` | Каким становится вид земли там, где меняется её высота; `null` — как в игре, `Dirt` |
| `KeepKind` | Земля вместо этого сохраняет свой вид: луг остаётся лугом, дорога дорогой. С `ClearVegetation` равным false остаётся и трава — для мягкого сглаживания природного склона, для холма посреди луга |
| `ClearVegetation` | Уходят ли трава, кусты и саженцы в области. Игра убирает их при любом изменении высоты; изменение вида земли их сохраняет |
| `OnlyOn` | Единственный вид земли, которого касается изменение: с `Natural` поднятие, сглаживание или биом оставляют дороги, тропы и перекопанную землю в области как есть |
| `Objects` | Что происходит с естественными объектами, стоящими там, где меняется земля |
| `Harvesting` | При `Objects = Harvest` — кто наносит удары и что игра за это даёт (`HarvestOptions`); `null` — никто |
| `KeepOffBuildings` | Отказывает ли изменение (`Blocked`), когда в области стоит постройка. Собственная проверка игры постройки не смотрит; SDK смотрит, если это не выключено |
| `KeepOffLandmarks` | То же для неподвижного места мира — логова или скал, с которыми место было создано. Игра не умеет двигать их вместе с землёй, поэтому выкопанная под ними земля оставит их висеть. По умолчанию включено |
| `ObstacleMode` | Что делает изменение там, где достаёт до того, от чего держится в стороне: `Refuse` (по умолчанию) отказывает целиком, `GoAround` делает изменение в обход этой земли, `Fit` — с подгонкой земли под тем, что там стоит |
| `UpdateNavigation` | Пересчитываются ли пути жителей и существ для новой земли, как это делает игра |

У каждого параметра по умолчанию поведение самой игры; `LandscapeOptions.Default` — то, с чем идёт изменение без
параметров. Изменение, ограниченное `OnlyOn` или сохраняющее свои объекты, всегда пишет SDK, какой бы ни была область.

:::warning[Одно изменение одной земли за кадр]
Поднятие, копание, выравнивание, покраску и очистку прямоугольника или кисти игра применяет позже в том же кадре.
Второе изменение той же земли в этом кадре прочитает землю такой, какой она была до первого, и запишет её обратно:
дорога, покрашенная и затем поднятая с `OnlyOn` в одном кадре, поднимется вместе со всем остальным. Делайте следующее
изменение кадром позже — в следующем `OnUpdate` или через `Dispatcher.MainThread.Post`.
:::

### Что стоит на пути {/* #what-stands-in-the-way */}

При `ObstacleMode`, отличном от `Refuse`, изменение делается там, где может, и отвечает `Partial`. В обход или с
подгонкой идёт след того, что там стоит: стены постройки и земля, которую игра под неё выравнивает, скалы логова,
запретная зона другого мода.

`Landscape.ObstaclesIn(area, options)` говорит, что это будет, ещё до изменения, — для предпросмотра:

```csharp
var options = new LandscapeOptions { ObstacleMode = LandscapeObstacleMode.GoAround };
LandscapeObstacles standing = Landscape.ObstaclesIn(area, options);
if (!standing.IsEmpty)
    Log.Info($"going round {string.Join(", ", standing.Names)}");

float after = standing.HeightAfter(x, z, Landscape.HeightAt(x, z), wanted);
```

| `LandscapeObstacles` | Что |
|---|---|
| `IsEmpty`, `Fits` | Пусто ли на пути и вмещается ли изменение в то, что там есть |
| `Names` | Что там стоит, по именам |
| `Covers(x, z)` | Может ли земля в точке не принадлежать изменению |
| `HeightAfter(x, z, now, changed)` | Какую высоту изменение оставит в точке: `now` под тем, что обходит, подогнанную — под тем, к чему подгоняется, иначе `changed` |
| `LandscapeObstacles.None` | На пути ничего |

`Landscape.Check(area, operation, options)` отвечает так же, как ответило бы изменение, не делая его: `Partial`, если
в области что-то стоит, а режим позволяет обойти это.

## Снимки {/* #snapshots */}

`Landscape.Capture(area)` сохраняет землю области такой, какая она сейчас, через каждые полметра: её высоты, её вид, её
растительность и её биом. Снимок живёт в памяти мода, а не в сохранении, и объекты мира в него не входят.

| `LandscapeSnapshot` | Что |
|---|---|
| `Area`, `CenterHeight` | Что сохранено и какой была высота земли в середине области |
| `HeightAt(x, z)` | Сохранённая высота в точке; `NaN` за пределами сохранённого |
| `Restore(options)` | Возвращает землю точно такой, какой она была сохранена, везде, куда достаёт область: отмена |
| `PasteAt(center, rotation, heightOffset, options)` | Укладывает ту же землю в другом месте, повёрнутой и поднятой или опущенной. Её высоты переходят в землю по весу области; там, где область хотя бы наполовину, с ними переносятся её вид и растительность, а биом у места остаётся свой |

Передайте `heightOffset: Landscape.HeightAt(x, z) - snapshot.CenterHeight`, чтобы уложить сохранённую землю
относительно земли на новом месте. Возврат газона 28 м из 613 точек занял в игре 19 мс, и ни вид, ни пометка, ни биом
не разошлись.

## Биом {/* #the-biome */}

Биом — это то, что растёт на земле (деревья, кусты и трава), и то, как она выглядит. Игра хранит по одному биому на
каждые `Landscape.BiomeCellSize` (4 м) мира.

Биом — это номер, а не название: каждая часть мира растит на нём свои растения, поэтому один и тот же номер — это
берёзовый лес в Зелёных землях и кипарисовый в болотах. Поэтому `LandscapeBiome.Name` — название того, что растёт на
нём в той части мира, где находится игрок, а два биома равны по одному `Id`.

| `Landscape` | Что |
|---|---|
| `Biomes` | Биомы, на которых часть мира, где находится игрок, растит свои растения, в порядке игры |
| `BiomeAt(x, z)` | Биом земли в точке; `null`, где он неизвестен |
| `FindBiome(name)` | Один из `Biomes` по названию в любом регистре (`"BirchForest"`); `null`, если такого нет |
| `PaintBiome(area, biome, options)` | Делает его биомом земли, так что растущее там тут же меняется на него |

```csharp
// Вырастить вокруг поселения берёзовый лес, только на природной земле.
if (Landscape.FindBiome("BirchForest") is { } birches)
    Landscape.PaintBiome(LandscapeArea.Circle(center, 24), birches,
        new LandscapeOptions { OnlyOn = GroundKind.Natural });
```

Клетка берёт новый биом там, где её середина лежит в области, а вес области в этом месте не меньше половины, так что
область меньше клетки может не изменить ни одной, а плавный край лишь расширяет её. Высота земли, её вид и пометка
убранной травы остаются, и стоящие там деревья, кусты и камни тоже остаются. Покраска 10 × 10 м заняла в игре 6 мс.

## Контур области {/* #an-areas-outline */}

`Landscape.ShowOutline(area, color)` рисует область на земле, следуя её высотам: предпросмотр того, куда пойдёт
изменение, или кисть под курсором. Контур рисуется только на этой машине, ни в одно сохранение не попадает и скрыт,
пока мир не загружен.

| `LandscapeOutline` | Что |
|---|---|
| `Area` | Обведённая область; её замена переносит контур |
| `Color` | Цвет линии |
| `IsVisible` | Показан ли он; скрытый контур сохраняет свою область и цвет |
| `Height` | На какой высоте над землёй идёт линия, от 0 до 10 м; по умолчанию 0,3, чтобы её не прятала трава |
| `LineWidth` | Ширина линии края, больше 0 и до 2 м; по умолчанию 0,2. Линия плавного края — 0,4 от неё |
| `Dispose()` | Убирает его с земли окончательно |

Край области — одна линия, внешний край плавного края прямоугольника или круга — вторая, тоньше. Линии рисуются
поверх всего, что стоит перед ними, так что камень или дерево на пути не прячет часть контура. Свойства можно
задавать из любого потока, они применяются в следующем кадре. Контур уходит, когда его освобождают или когда его мод
отключается после ошибки.

## Инструменты на земле {/* #tools-on-the-ground */}

Инструменту, который работает с землёй под курсором, кроме контура нужны ещё две вещи: куда указывает курсор и
картинка того, что сделает изменение, ещё до того, как оно сделано.

### Земля под курсором {/* #the-ground-under-the-cursor */}

`Landscape.TryRaycast(ray, maxDistance, out point)` находит, где луч впервые встречает землю, с точностью до
сантиметра. Луч под курсором — `GameCamera.ScreenPointToRay(MouseInput.Position)` (модули камеры и интерфейса;
[Мышь и клавиатура](ui/input.md)):

```csharp
Ray ray = GameCamera.ScreenPointToRay(MouseInput.Position);
if (Landscape.TryRaycast(ray, Landscape.MaximumRayDistance, out Vector3 point))
    brush.Area = LandscapeArea.Circle(point, radius);
```

Считается только земля: постройки, деревья и невидимые объёмы игры луч не останавливают, поэтому кисть ложится на
землю за домом, а не на его крышу. `maxDistance` — больше 0 и не больше `MaximumRayDistance`, 2000 м. Ответ —
`false` для луча, который не встречает загруженной земли на этом расстоянии, для луча, начинающегося под землёй, и для
вызова не из главного потока.

Инструмент, который работает с тем, что стоит на земле, — ластик, убирающий валун, — спрашивает, на что указывает
курсор: `GameCamera.TryRaycast(ray, maxDistance, out point, out target)` даёт первое, что встречает луч, — камень или
ствол так же, как землю; локальный игрок и невидимые объёмы игры не учитываются ([Камера](camera.md)):

```csharp
Ray ray = GameCamera.ScreenPointToRay(MouseInput.Position);
if (Landscape.TryRaycast(ray, Landscape.MaximumRayDistance, out Vector3 ground))
{
    // На валуне кисть встаёт под ту его часть, на которую указывает курсор, а не на землю за ним.
    if (GameCamera.TryRaycast(ray, Landscape.MaximumRayDistance, out Vector3 onObject, out _)
        && (onObject - ray.origin).sqrMagnitude < (ground - ray.origin).sqrMagnitude)
        ground = new Vector3(onObject.x, Landscape.HeightAt(onObject.x, onObject.z), onObject.z);
    brush.Area = LandscapeArea.Circle(ground, radius);
}
```

### Сетка ячеек {/* #a-grid-of-cells */}

`Landscape.ShowGrid(center, columns, rows, cellSize, rotation)` рисует на земле сетку в виде поля выравнивания игры:
каждая ячейка в рамке, прозрачная, лежит по рельефу, траве и камням. Мод красит каждую ячейку, чтобы показать, что там
сделает изменение:

```csharp
LandscapeGrid grid = Landscape.ShowGrid(point, columns: 8, rows: 8, cellSize: 1);
for (int c = 0; c < grid.Columns; c++)
    for (int r = 0; r < grid.Rows; r++)
    {
        Vector3 cell = grid.CellCenter(c, r);
        if (!Landscape.TryGetHeight(cell.x, cell.z, out float ground)) continue;
        float off = Mathf.Abs(ground - target);
        if (off > 4) grid.MarkCell(c, r);                // слишком далеко, не достать
        else if (off > 0.05f) grid.SetCell(c, r, off / 4); // оттенок: насколько сдвинется земля
        // иначе ячейка остаётся пустой: земля уже какая надо
    }
```

| `LandscapeGrid` | Что |
|---|---|
| `SetCell(column, row, fraction)` | Оттенок между `NearColor` (при 0) и `FarColor` (при 1) |
| `MarkCell(column, row)` | Красный цвет игры — так поле выравнивания показывает землю, которую выровнять не может. Перекрасить его нельзя |
| `ClearCell(column, row)` | Видна только рамка ячейки |
| `Clear()` | Все ячейки пусты |
| `NearColor`, `FarColor` | Цвета оттенков; `null`, по умолчанию, — собственные зелёные игры |
| `Center` | Середина сетки; её замена переносит сетку |
| `Rotation` | Насколько сетка повёрнута вокруг вертикали, в градусах, как `LandscapeArea.Rectangle` |
| `CellCenter(column, row)` | Середина ячейки на земле (y 0), с учётом поворота |
| `Columns`, `Rows`, `CellSize` | Её размер, заданный при создании |
| `IsVisible` | Показана ли она; скрытая сетка сохраняет свои ячейки |
| `Dispose()` | Убирает её с земли окончательно |

Столбцы идут вдоль x, строки — вдоль z до поворота сетки: ячейка (0, 0) — угол с наименьшими x и z. В сетке от 1 до
256 столбцов и строк (`LandscapeGrid.MaximumCells`) размером от 0,25 до 16 м (`MinimumCellSize`, `MaximumCellSize`).
Свойства и ячейки можно задавать из любого потока, сетка перерисовывается в следующем кадре. Как и контур, она
рисуется только на этой машине, ни в одно сохранение не попадает, скрыта, пока мир или её середина не загружены, и
уходит, когда её освобождают или её мод отключается после ошибки.

## Запретные зоны {/* #protected-zones */}

`Landscape.Protect(area)` сохраняет землю области такой, какая она есть: ни одно изменение, сделанное на этой машине,
в неё не заходит — ни инструменты игрока, ни жители, ни площадка или поле постройки, ни сама игра, ни другие моды.
Мод, поставивший зону, свою землю по-прежнему меняет. Зона живёт в памяти мода, а не в сохранении.

```csharp
LandscapeZone shrine = Landscape.Protect(LandscapeArea.Circle(altar, 8));
shrine.Refused += (_, e) => Log.Info($"{e.Source} tried to {e.Operation} at the shrine");
// ...
shrine.Dispose();   // землю снова можно менять
```

| `LandscapeZone` | Что |
|---|---|
| `Area` | Защищаемая земля; замена области переносит зону |
| `ModId` | Мод, который её поставил и чьи собственные изменения она пропускает |
| `IsActive` | Защищает ли она ещё: `false` после освобождения или когда её мод отключён |
| `Refused` | Вызывается с отклонённым изменением, уже отменённым |
| `Dispose()` | Снова разрешает менять землю |

Изменение отклоняется, когда прямоугольник, который оно задевает (вместе с плавным краем), достаёт до собственной
фигуры зоны — до земли, где вес её области не меньше половины. Игра тогда отвечает инструменту игрока или жителя так
же, как на место, которое она копать не станет, изменение мода получает `Blocked`, и `Check` говорит об этом ещё до
того, как что-то сделано. Чтение не отклоняется никогда.

Видны только изменения этой машины: игра другого игрока делает и отправляет свои, а выравнивание по плану дороги не
видно вовсе. В сетевой игре зона нужна в игре каждого игрока.

:::warning[Не ставьте поля выравнивания в зону]
Игра отмечает плитку поля обработанной до того, как отработает её инструмент, поэтому отклонённый удар всё равно
засчитывает плитку выровненной: поле, поставленное в зоне и обработанное жителями, завершится с нетронутой землёй.
`LevellingField.LevelNow` пропускает плитки, которые удерживает зона другого мода.
:::

## События {/* #events */}

```csharp
Landscape.GroundChanging += (_, e) =>
{
    // Жителям нельзя копать в роще.
    if (e.Source == LandscapeSource.Resident && e.Area.Overlaps(grove)) e.Cancel = true;
};

Landscape.GroundChanged += (_, e) => Log.Info($"{e.Operation} в {e.Area} от {e.Source}");
```

`GroundChanging` вызывается на этой машине перед изменением земли, кем бы оно ни делалось: инструментом игрока,
жителем, постройкой, модом или игрой. Обработчик может его отменить, и игра тогда отвечает так же, как на отказ
поставить что-то. `GroundChanged` вызывается после того, как земля изменилась, здесь или на машине другого игрока,
когда её новые высоты уже видны.

| Аргументы обоих событий | Что |
|---|---|
| `Area` | Земля, которую изменение задевает, примерно: x — это x мира, y — z мира |
| `Operation` | Что делается. `null` в `GroundChanged` для изменения, пришедшего по сети |
| `Source` | Кто его делает |
| `ModId` | Мод, который делает его через `Landscape`, или `null`, когда это игра |

У `LandscapeChangedEventArgs` есть ещё `IsRemote` — true для изменения с машины другого игрока. Изменения, пришедшие
по сети, сообщает только `GroundChanged`: игра, которая их сделала, вызвала `GroundChanging` у себя. Выравнивание по
плану дороги тоже сообщает только `GroundChanged`.

| `LandscapeSource` | Кто |
|---|---|
| `Player` | Игрок с инструментом в руках |
| `Resident` | Житель на работе |
| `Building` | Постройка: выровненная площадка под ней, вспаханное поле, план выравнивания или дороги в работе |
| `Mod` | Мод, через `Landscape`; `ModId` говорит, какой |
| `Remote` | Игра другого игрока, по сети (только `GroundChanged`) |
| `Other` | Что-то ещё в игре |

| `LandscapeOperation` | Что |
|---|---|
| `Raise`, `Lower`, `Level` | Земля идёт вверх, вниз или к одной высоте |
| `Paint` | Её вид меняется; её высота остаётся |
| `ClearVegetation`, `RestoreVegetation` | Её трава и кусты уходят или её собственный вид и трава возвращаются |
| `Smooth`, `Slope`, `Shape` | Сглажена, сделана пандусом или получила собственные высоты мода |
| `Restore`, `Paste` | Снимок возвращён или уложен в другом месте |
| `PaintBiome` | Её биом меняется, а с ним и то, что там растёт |

## Объекты мира {/* #the-worlds-objects */}

`NaturalObjects` даёт деревья, камни, кусты, гнёзда и грибы, которые вырастил мир, и предметы, лежащие на земле, —
ближайшие первыми.

| `NaturalObjects` | Что |
|---|---|
| `In(area)` | Все объекты, место которых хотя бы наполовину в области |
| `Around(center, radius)` | В пределах заданных метров, не больше `MaximumRadius` (64 м) |
| `Touching(center, radius)` | Те, что заходят в круг: чьё место в нём, и те, чей след на земле заходит в него, хотя место снаружи |
| `Nearest(center, radius)` | Ближайший или `null` |

`Around` и `In` смотрят на место объекта — одну точку. У большого валуна или прибрежной скалы место может стоять в
нескольких метрах от той части, на которую указывает игрок; инструмент, забирающий то, что под кистью, спрашивает
`Touching`, и валун, который кисть накрывает лишь частью, всё равно находится.

| `NaturalObject` | Что |
|---|---|
| `AssetName` | Название в игре того, что это (`"Harvest_Wood_birch1"`) |
| `Kind` | Какого рода эта вещь |
| `ResourceName` | Название в игре предмета, который даёт сбор (`"Item_Wood_birch1"`), или `""` |
| `Position`, `HeightOverGround` | Где он стоит и насколько выше или ниже земли под ним |
| `Health`, `Quantity` | Сколько от него осталось, как игра считает это для дерева или залежи, и сколько осталось его ресурса |
| `IsRemovable` | Забирает ли его изменение земли: куст или небольшой камень — да, дерево или валун — нет |
| `IsClearable` | Забирает ли его `Clear`: дерево и валун тоже, насколько это позволяет собственная очистка игры |
| `IsHarvestable`, `GatherCount` | Может ли игрок собрать или срубить его и сколько предметов ещё можно собрать руками |
| `IsGone` | Нет ли его больше в мире. Спрашивайте объекты заново, а не держите один надолго |
| `Gather(charges)` | Собирает с него так же, как игрок руками: предметы падают на землю рядом, его количество уменьшается, а игра сообщает об этом другим игрокам. Отвечает, сколько предметов он дал |
| `Harvest(options)` | Рубит или добывает его так же, как это делают дровосек и рудокоп, удар за ударом, пока ничего не останется: дерево падает, его ствол распиливается, каменная глыба даёт камень. Добыча — собственная игровая, падает рядом, и инструмент не нужен |
| `Remove()` | Убирает его из мира так же, как это делает изменение земли. Дерево или валун остаётся |
| `Clear()` | Убирает его, что бы это ни было, дерево или валун тоже, и ничего не роняет. Обратно он не появляется: сохранение помнит, что его нет |
| `Settle()` | Ставит его на землю под ним, чтобы дерево, оставшееся в воздухе после изменения, снова стояло на ней |
| `MoveTo(position)` | Переносит его куда угодно вместе с видимой моделью. Собственные проверки игры о том, где вещь может стоять, не делаются |

Дерево рубят, а не собирают руками, поэтому `GatherCount` и `Gather` отвечают для него 0. `Settle` и `MoveTo` по
сети не уходят: другие игроки видят объект там, где он стоял, пока не загрузят эту часть мира снова.

`Harvest` работает с тем, что игра рубит или добывает, — деревьями, пнями, стволами, каменными глыбами и залежами —
и только с объектом, который игра подняла вокруг игрока. Куст с ягодами, грядку или гнездо собирают руками
(`Gather`), а декоративный валун не даёт вообще ничего: его забирает только `Clear`.

| `HarvestOptions` | Что |
|---|---|
| `AsPlayer` | Бьёт ли локальный игрок: тогда игра даёт ему опыт работы, свой шанс рабочей травмы и запись о добыче в деяниях. По умолчанию `false` — не бьёт никто, игра ничего никому не начисляет, а добыча падает всё равно |
| `AwardExperience`, `AllowInjuries` | При `AsPlayer` — начислять ли опыт и допускать ли травмы. Оба по умолчанию включены |
| `ChopTrunk` | Распиливать ли ствол, который оставляет упавшее дерево, на брёвна, палки и кору. По умолчанию включено; игра разрешает бить по стволу лишь спустя мгновение после падения, поэтому он распиливается через несколько секунд |

| `NaturalObjectKind` | Что |
|---|---|
| `Grass` | Трава и подобное, рисуемое тысячами: отдельного объекта в мире нет |
| `Plant` | Растение: лён, куст с ягодами, гриб |
| `Tree` | Дерево |
| `Object` | Вещь мира: небольшой камень, гнездо, бревно |
| `LargeObject` | Большая вещь: валун, скальный камень, залежь руды |
| `Item` | Предмет, лежащий в мире: выброшенный игроком или посаженный в землю саженец |
| `Other` | Что-то ещё или то, о чём игра не говорит |

`LandscapeOptions.Objects` говорит, что изменение земли с ними делает:

| `LandscapeObjects` | Что |
|---|---|
| `Remove` | Как в игре: кусты, саженцы и небольшие камни, которые забирает изменение, забираются |
| `Keep` | Ничего не забирается: объекты остаются там, где стояли, теперь над или под новой землёй |
| `Settle` | Ничего не забирается: каждый объект области ставится на новую землю под ним |
| `Clear` | Забираются все объекты, деревья и валуны тоже, и ничего не роняется; лежащие там предметы остаются |
| `Harvest` | Все объекты забираются вместе с добычей, когда земля уже изменилась: что игра рубит — рубится, что собирают руками — отдаёт всё, остальное убирается. Кто бьёт, говорит `LandscapeOptions.Harvesting` |

### Пометка объектов {/* #marking-objects */}

`NaturalObjects.ShowMarks()` закрашивает объекты полупрозрачным красным самой игры — тем, которым она отмечает то, что
мешает поставить постройку: так инструмент показывает, что он сейчас заберёт.

```csharp
ObjectMarks marks = NaturalObjects.ShowMarks();
// Каждый кадр или несколько раз в секунду: что забрал бы ластик под курсором.
marks.Set(NaturalObjects.Touching(cursor, radius).Where(o => o.Kind != NaturalObjectKind.Item));
// …
marks.Dispose();
```

| `ObjectMarks` | Что |
|---|---|
| `Set(objects)` | Помечает эти объекты и никакие другие, не больше `MaximumCount` (128); пустой список снимает все пометки |
| `Count` | Сколько объектов помечено |
| `IsVisible` | Показаны ли пометки; скрытые сохраняют свои объекты |
| `Dispose()` | Снимает все пометки окончательно |

Каждая пометка — копия модели объекта на его месте, повёрнутая и с размером как у объекта и чуть крупнее, чтобы
лежать поверх него. Это изображение только на этой машине. `Set` вызывается в главном потоке; пометки видны со
следующего кадра и уходят вместе со своим объектом, при освобождении или когда их мод отключается после ошибки.

### Расстановка объектов {/* #placing-objects */}

`NaturalObjects.Place` ставит в мир вид из его собственных: дерево, куст, грядку, камень, декоративный валун.
Поставленное рубится, собирается или убирается так же, как этот вид, сохраняется с миром и уходит другим игрокам,
которым для него нужен тот же Mjolnir. Куст появляется полным, а собранный до конца остаётся и снова даёт урожай
тогда же, когда его дают кусты мира того же вида, — ягодные кусты в начале сезона.

```csharp
PlaceableKind? willow = NaturalObjects.FindKind("tree_willow");

// Саженец в треть взрослого размера: он дорастёт до него за дни мира.
NaturalObject? young = NaturalObjects.Place("tree_willow", position, rotation: 30f, scale: 0.3f);
```

| `NaturalObjects` | Что |
|---|---|
| `Kinds` | Все виды, которые может поставить мод: их 70 — всё, что растит мир, кроме травы. Готовы, как только игра построит базу предметов, уже в главном меню |
| `FindKind(name)` | Вид по названию (`"tree_willow"`) или по имени ассета; `null`, если такого нет |
| `Place(kind, position, rotation, scale)` | Ставит его, беря y от земли. Масштаб — не больше `MaximumScale` (4); для дерева это его возраст |
| `TreeGrowthDays` | За сколько дней мира поставленное дерево вырастает с нуля до взрослого размера: по умолчанию 32, столько же растёт берёзовый саженец самой игры, а 0 останавливает рост. Значение общее для деревьев всех модов, поэтому меняйте его только по просьбе игрока |
| `PictureOf(kind, width, height)` | Картинка вида для палитры или списка: его модель в три четверти на тёмном фоне меню строительства. Снимается при первом запросе и хранится до конца запуска игры; не больше `MaximumPictureSize` (1024) по стороне |
| `ShowPreview(kind, position)` | Модель вида, стоящая на земле призраком под курсором, пока её не освободят |

| `PlaceableKind` | Что |
|---|---|
| `Name`, `AssetName` | Название вида в игре (`"tree_willow"`) и имя того, что ставится (`"Mjolnir_World_tree_willow"`) |
| `DisplayName` | Его название для игрока, на языке игрока, если оно есть у игры, иначе сделанное из `Name` (`"tree_birch1"` → `"Birch 1"`) |
| `Kind` | Дерево, вещь, большая вещь или растение |
| `MinimumScale`, `MaximumScale` | Масштабы, в которых его растит сам мир: дерево меньше их стоит молодым и дорастает до взрослого размера |
| `IsHarvestable`, `IsGathered` | Рубится ли и добывается ли он и собирают ли его руками |

Дерево, поставленное меньше своего взрослого размера — масштаба между `MinimumScale` и `MaximumScale` его вида,
одинакового для этого места на всех машинах, — дорастает до него по часам мира, пока стоит; пень не растёт, а дерево,
поставленное взрослым или больше, остаётся как есть. Растит его хост, пока дерево рядом с игроком; игра сохраняет
масштаб и отправляет его другим игрокам. Ива, поставленная с масштабом 0,3, доросла до 1,265 и остановилась.

`ShowPreview` даёт `KindPreview` — только изображение: его нельзя срубить, он ни с чем не сталкивается и не
сохраняется, и рисуется лишь на этой машине. Двигайте его через `Position`, поворачивайте и меняйте размер через
`Rotation` и `Scale`, меняйте показанный вид через `Kind`, скрывайте через `IsVisible`, а `IsBlocked` рисует его
полупрозрачным красным игры там, где объект ставить нельзя. Свойства можно задавать из любого потока, они применяются в следующем кадре.

## Поля выравнивания {/* #levelling-fields */}

Поле выравнивания — это план, который игрок ставит, чтобы жители выровняли землю по плиткам до одной высоты. Мод
ставит такой же и может выровнять его сразу, не дожидаясь жителей. Игра сохраняет поле и отправляет его другим
игрокам.

| `LevellingFields` | Что |
|---|---|
| `All` | Поля выравнивания загруженного мира |
| `Nearest(center, radius)` | Поле, ближайшее к точке, или `null` |
| `Place(area)` | Ставит поле по области: сетку из целых плиток по `TileSize` (2 м), уложенную по осям мира и подогнанную к середине области. Не больше `MaximumTiles` (256) — столько позволяет собственный план игры |

Поворот области не используется, а её плавный край не считается: сетку задают собственные стороны области,
округлённые до целых плиток.

| `LevellingField` | Что |
|---|---|
| `Center`, `Width`, `Depth` | Где поле и насколько велико, в метрах |
| `Tiles`, `LevelledTiles`, `IsLevelled` | Сколько у него плиток, сколько выровнено и выровнены ли все |
| `Height`, `HeightDifference` | Высота, к которой идут его плитки, и насколько его земля ещё отстоит от неё в худшем месте |
| `IsGone` | Нет ли плана больше в мире: закончен, убран или вне загруженной части |
| `LevelNow()` | Выравнивает все оставшиеся плитки так же, как жители выравнивают их мотыгами. Отвечает, сколько выровнено теперь |
| `Finish()` | Превращает план в то, что он строит, как делает игра, когда план выровнен. Простое поле выравнивания ничего не строит, поэтому оно просто уходит |
| `Remove()` | Убирает план так же, как игрок его разбирает, оставляя землю как есть |

Игра сама заканчивает план, у которого выровнена последняя плитка, поэтому сразу после того, как `LevelNow()`
выровнял все, поле уже `IsGone` и заканчивать (`Finish`) нечего. `HeightDifference` считается по отрисованной земле,
поэтому после `LevelNow()` оно обновляется только в следующем кадре.

## Планы дорог {/* #road-plans */}

План дороги — это линия, которую игрок ставит дорожником: жители приносят всё нужное, а затем выравнивают и мостят
её по участкам. Мод ставит такой же и может построить и замостить его сразу.

```csharp
if (RoadPlans.Place([gate, bend, well]) is { } road)
{
    road.Width = 6f;    // шире, чем у игры, — на этой машине
    road.LevelNow();    // построен, выровнен и замощён сразу
}
```

| `RoadPlans` | Что |
|---|---|
| `All`, `Nearest(center, radius)` | Планы дорог загруженного мира и ближайший к точке |
| `Place(points, kind, width)` | Ставит план по 2–`MaximumPoints` (8) точкам, не длиннее `MaximumSections` (96) участков по `SectionLength` (2 м). `kind` — `Road` по умолчанию или `Dirt`, план выравнивания по линии, который выравнивает полосу и оставляет голую землю. `width` 0 — ширина игры. Собственные проверки дорожника — повороты, уклон, вода — не делаются |

| `RoadPlan` | Что |
|---|---|
| `Points`, `Kind` | Где он проходит и что кладёт |
| `Width` | Какой ширины полосу выравнивает каждый участок. Дорога игры выравнивает 3,5 м и мостит примерно на метр меньше в середине; ширина мода — от `MinimumWidth` (1 м) до `MaximumWidth` (16 м) с шагом `WidthStep` (0,5 м), промежуточная округляется до ближайшего шага |
| `Sections`, `LevelledSections`, `IsLevelled` | Сколько у него участков, сколько выровнено и замощено и все ли |
| `IsBuilt` | Принесли ли жители всё нужное — или это сделал `Build` |
| `IsGone` | Нет ли плана больше в мире: дорога закончена, план убран или вне загруженной части |
| `Build()` | Строит его сразу, как будто жители всё принесли |
| `LevelNow()` | Строит, если он ещё не построен, затем выравнивает и мостит все оставшиеся участки. Отвечает, сколько сделано теперь |
| `Remove()` | Убирает план, оставляя землю как есть |

Игра сама заканчивает дорогу, у которой замощён последний участок, поэтому сразу после того, как `LevelNow()` сделал
все, план уже `IsGone`. Участок, который удерживает запретная зона другого мода, остаётся нетронутым.

`RoadPlans.Line(points, kind)` даёт линию, по которой пошёл бы план через эти точки, не ставя его, — для
предпросмотра, пока игрок её рисует. У `RoadLine` есть `Samples` — точки на земле на высотах, до которых выровняли бы
участки, — `Length`, `Sections` и `Fits`: может ли план вообще по ней пройти, то есть хотя бы один участок и не
больше `MaximumSections`.

Заданная модом ширина остаётся с планом: по ней выравнивают и жители, игра сохраняет её и отправляет другим игрокам —
которым для этого нужен тот же Mjolnir, — и она держится после новой загрузки мира.

## Пруды {/* #ponds */}

Пруд — вода, которую мод наливает в вырытую им котловину. `WaterBodies.Place` заполняет котловину, в которой лежит
точка, до заданного уровня: так далеко, как от точки тянется земля ниже этого уровня, в пределах квадрата вокруг неё.
Вода — та же, что в озёрах игры, с берегом и отражениями; персонаж в ней плавает, на вопрос игры, какая вода стоит в
точке (его задают существа и рыбалка), отвечает пруд, а игра сохраняет пруд и рассылает его другим игрокам. Форма пруда —
форма земли: расширьте берег, и вода дойдёт туда в следующем кадре.

```csharp title="PondMod.cs"
using Mjolnir.SDK;
using Mjolnir.SDK.Terrain;
using UnityEngine;

namespace PondMod;

[ModManifest("author.pond", "Pond", "1.0.0")]
public sealed class PondMod : Mod
{
    // Круглый пруд у точки: котловина в 3 м, вода на полметра ниже самого низкого места кромки.
    public static WaterBody? Dig(Vector3 at)
    {
        if (Landscape.Lower(LandscapeArea.Circle(at, 8, 4), 3f) != LandscapeResult.Done) return null;
        float rim = float.MaxValue;
        for (int k = 0; k < 36; k++)
        {
            var edge = at + Quaternion.Euler(0, k * 10, 0) * Vector3.forward * 13f;
            rim = Mathf.Min(rim, Landscape.HeightAt(edge.x, edge.z));
        }
        var fill = WaterBodies.Measure(at, rim - 0.5f, 40);
        return fill.Result == WaterFillResult.Fits ? WaterBodies.Place(at, rim - 0.5f, 40) : null;
    }
}
```

Изменение земли видно кадром позже (см. предупреждение выше): мерьте и ставьте пруд в кадре после того, как вырыта
котловина.

| `WaterBodies` | Что |
|---|---|
| `All` | Все пруды мира и озёра загруженной части |
| `At(x, z)`, `Nearest(center, radius)` | Пруд или озеро, чья вода покрывает точку, и то, чья середина ближе всех |
| `Measure(point, level, size)` | Что покрыл бы пруд, налитый от `point` до `level`, не ставя его: `WaterFill` для предпросмотра. `size` — сторона квадрата вокруг точки, дальше которого вода не идёт, от `MinimumSize` (4 м) до `MaximumSize` (128 м); по умолчанию 64 |
| `Place(point, level, size)` | Заполняет котловину, если вода в ней держится, и даёт `WaterBody`; null, где не держится (причину даёт `Measure`) |

| `WaterFillResult` | Почему |
|---|---|
| `Fits` | Котловина держит воду: пруд можно поставить |
| `Spills` | Вода доходит до края квадрата: котловина на этом уровне открыта или больше квадрата |
| `AboveLevel` | Земля в точке на уровне или выше: заполнять нечего |
| `InWater` | Точка уже в воде: в море, озере или пруду |
| `Overlaps` | Вода слилась бы с водой пруда или озера |
| `NotLoaded` | Часть квадрата не в загруженной части мира |
| `NotAvailable` | Мир не загружен, или это не главный поток |

`WaterFill` говорит свой `Result`, `Level`, квадрат, в котором лежит его вода (`Bounds`), `Area` в квадратных метрах и
`Volume` в кубических, а `Covers(x, z)` и `DepthAt(x, z)` — про точку. Землю он читает не чаще, чем через полметра (в
квадрате больше 64 м — реже).

| `WaterBody` | Что |
|---|---|
| `Center`, `Level` | Точка, от которой налит пруд, на высоте поверхности, и эта высота |
| `Size`, `Bounds` | Сторона его квадрата и квадрат, в котором лежит его вода сейчас |
| `Area`, `Volume` | Поверхность в квадратных метрах и вода в кубических, как налито сейчас; у озера 0 |
| `Covers(x, z)`, `DepthAt(x, z)` | Покрывает ли его вода точку и какая там глубина |
| `IsWorldLake` | Озеро мира: мод его читает, но не меняет |
| `IsGone` | Убран или его больше нет в мире |
| `Remove()` | Убирает пруд — с сохранением и у других игроков; у озера false |

`Landscape.IsUnderwater` в пруду true, как в озере. Пить из пруда нельзя, как и из озёр игры. В консоли `water`
перечисляет пруды и озёра, `water fill [depth] [size]` наливает воду в котловину перед игроком на `depth` выше земли там,
а `water remove` убирает ближайший пруд.
