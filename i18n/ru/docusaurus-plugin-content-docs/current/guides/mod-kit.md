# Mod kit

`unity/Mjolnir.ModKit` в репозитории — проект Unity для ассетов мода: моделей предметов, анимаций и масок, которые
собираются в AssetBundle для игры. Он работает на собственной версии Unity игры, **6000.3.12f1**, с **HDRP** 17.3.0 —
конвейером рендеринга игры.

## Настройка {/* #setting-up */}

1. Установите Unity **6000.3.12f1** через Unity Hub и откройте в нём `unity/Mjolnir.ModKit`. Первый импорт идёт
   долго: HDRP компилирует свои шейдеры.
2. Окно **Mjolnir → Kit Window** открывается само в первый раз. В нём перечислено, что нужно mod kit, — каждый
   недостающий шаг с кнопкой, которая его выполняет: нужная версия Unity, HDRP в линейном цвете, найденная игра,
   установленный в неё Mjolnir, импортированные скелеты игры. Там же — ваши моды с их бандлами и инструменты mod kit.

При открытии mod kit включает HDRP на всех уровнях качества и линейное цветовое пространство
(**Mjolnir → Set Up the Kit** делает это снова), чтобы цвета и текстуры выглядели так же, как в игре. Игру он находит
по `MJOLNIR_GAME_DIR`, по выбранной ранее папке или по записям Steam, а если не находит — спрашивает.

## Бандлы мода {/* #a-mods-bundles */}

- **Mjolnir → New Mod…** создаёт `Assets/Mods/<mod>/<bundle>/`. Называйте папку мода так же, как в `Mjolnir/Mods`
  игры. Каждая папка бандла становится одним AssetBundle со всем своим содержимым.
- **Mjolnir → Build Bundles** собирает их в `Build/Bundles/<mod>/<bundle>`. Каждый бандл собирается под именем своего
  мода, поэтому бандлы двух модов с одним именем папки, например `models`, загружаются в игре вместе. Пересоберите
  бандлы, собранные старой версией mod kit.
- **Mjolnir → Build and Copy to Game** ещё и копирует каждый бандл в `Mjolnir/Mods/<mod>/bundles/` установленного
  мода, а отрендеренные иконки предметов — в его `items/`. Файл, который держит открытым запущенная игра, называется в
  сообщении, а сборка на нём не прерывается.
- **Mjolnir → Check Mods** предупреждает о том, что не будет работать в игре: шейдер не из `HDRP/…`, скрипт на
  префабе, опорная точка в стороне от модели, кость клипа или маски, которой нет ни у одного скелета игры, бандлы,
  которые игра не загрузит вместе. Проверка
  запускается и перед каждой сборкой. Щелчок по её строке в Console показывает ассет.

Инструменты для ассетов есть и в контекстном меню окна Project, в подменю **Mjolnir**: Preview Animation, Render Item
Icons, New Mask from Clip и Keep Every Bone работают с выбранным ассетом.

`tools/build-bundles.ps1` в репозитории запускает mod kit в пакетном режиме. Unity блокирует открытый проект: сначала
закройте редактор или соберите из его меню и запустите скрипт с `-SkipBuild`.

## Скелеты игры {/* #the-games-skeletons */}

Анимации и маски делаются на собственных скелетах игры:

1. Запустите игру с Mjolnir один раз. Она запишет скелеты персонажей (имена костей и их позу, больше ничего из игры) в
   `Mjolnir/ModKit/rigs/`.
2. Выполните **Mjolnir → Rigs → Import from the Game**. Команда создаёт `Assets/Mjolnir/Rigs/<rig>.prefab`, каждый с
   Animator и generic-аватаром:

| Скелет | Персонажи |
|---|---|
| `ragnar`, `aska` | Мужской и женский персонажи игрока |
| `peasant_male`, `peasant_female` | Жители |

Имена костей у всех четырёх одинаковы, поэтому клип, сделанный на одном, играет на остальных; пропорции у них разные.
`CharacterAnimator.Rig` называет скелет персонажа в игре.

Две настройки на странице настроек Mjolnir в игре (кнопка **Настройки** в окне Mjolnir) переносят в mod kit больше из
игры. Обе по умолчанию выключены:

| Настройка | Что игра пишет в `Mjolnir/ModKit` | В mod kit |
|---|---|---|
| Модели персонажей для набора | Меши людей и их карты цвета, нормалей и масок, около 160 МБ | Импорт одевает в них скелеты, с причёской и бородой по умолчанию |
| Анимации игры для набора | Все клипы, которые двигают скелет людей, около 730 | Preview Animation перечисляет их, чтобы проиграть на персонажах |

Всё, что игра пишет туда, принадлежит ей: оно остаётся на вашем компьютере, вне git и вне любого бандла.

**Mjolnir → Rigs → Export as FBX** записывает каждый скелет с привязанной к нему фигуркой из палочек в
`Build/Rigs/<rig>.fbx` — для анимации в другой программе.

## Предпросмотр анимаций {/* #previewing-animations */}

- **Mjolnir → Animation → Open Preview Stage** открывает сцену предпросмотра, где персонажи игры стоят в позе покоя:
  земля из метровых квадратов, солнце и небо.
- **Mjolnir → Animation → Preview Animation** проигрывает на них клип: Play, Pause, Stop, Loop, In place (root motion
  удерживается на месте), скорость от ×0,1 до ×2, время и кадр. **Choose…** перечисляет клипы ваших модов по модам и
  бандлам, а клипы игры — по скелетам; окно также следует за клипом, выбранным в окне Project. Сцена никогда не
  меняется.
- Для клипа игры **Save as Asset** сохраняет копию в mod kit для окна Animation.

## Создание анимаций {/* #making-animations */}

Клип для мода получают одним из трёх способов.

**В Unity.** Анимируйте импортированный скелет в окне Animation.

**Из Blender** (так же — для Maya, 3ds Max и Cascadeur; проверен только Blender):

1. **Mjolnir → Rigs → Export as FBX**.
2. В Blender — **File → Import → FBX** с настройками по умолчанию. Верхняя кость скелета, `master`, становится
   объектом арматуры: анимируйте кости в режиме Pose, а для root motion двигайте объект арматуры. Одно действие
   (action) — один клип, названный по действию.
3. **File → Export → FBX** с настройками по умолчанию — в папку бандла мода.

При импорте mod kit подгоняет файл под скелет игры, и бандл берёт клипы файла, каждый под именем его действия. Blender
записывает каждую кость, нетронутые — в позе покоя; кость, которая весь клип остаётся в покое, mod kit оставляет
собственной анимации игры, поэтому клип, поднимающий руку, двигает только руку, а персонаж под ним идёт.
**Mjolnir → Animation → Keep Every Bone** на файле сохраняет все кости — для позы, которая должна удерживать и
остальные.

**Из Mixamo** или другого гуманоидного источника:

1. Скачайте анимацию в FBX: Without Skin, 30 fps, без прореживания ключей; для ходьбы выключите In Place, чтобы
   сохранить её перемещение.
2. Положите её в папку бандла мода. Mod kit видит скелет не из игры и делает файл гуманоидным источником: он остаётся
   вне бандла, а его клип называется по имени файла.
3. **Mjolnir → Animation → Bake Humanoid Clips to Rig…** записывает его кость за костью на скелете игры, а ноги
   удерживаются на земле собственными целями стоп клипа. In Place убирает движение вперёд.

Лицензия Mixamo разрешает использовать его анимации в игре, но не распространять файлы: не кладите их в публичный
репозиторий.

## Маски {/* #masks */}

- **Mjolnir → Animation → New Mask from Clip** создаёт рядом с клипом `<clip>Mask.mask`: ровно те кости, которые
  двигает клип. Проигранный через неё, клип оставляет все остальные кости игре.
- **Mjolnir → Animation → New Mask…** создаёт пустую маску по скелету игры, чтобы заполнить её вручную.

Пути маски — пути скелета от его корня (`master/Bip001/…`). В моде:

```csharp
ModAnimation wave = Animations.Add("wave", "bundles/anims", "Wave");             // бандл, имя клипа
AnimationMask waveMask = AnimationMask.Add("wave", "bundles/anims", "WaveMask");  // New Mask from Clip
LocalPlayer.Animator.Play(wave, new AnimationOptions { Mask = waveMask });       // рука машет, игрок идёт дальше
```

См. [Анимации](animations.md).

## Ассеты игры не попадают в мод {/* #the-games-assets-stay-out */}

Мод проигрывает собственные клипы игры по имени (`Animations.Find("aska_wave")`) и никогда их не поставляет. Mod kit
отказывается собирать бандл, который взял бы клип игры или его копию, модель или скелет персонажа или что-либо,
помеченное как принадлежащее игре, а Check Mods называет это.
