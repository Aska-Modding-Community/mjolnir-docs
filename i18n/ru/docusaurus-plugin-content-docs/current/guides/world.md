# Часы мира

`Mjolnir.SDK.World` читает и устанавливает часы загруженного мира. Подключите `Mjolnir.SDK.World.dll` и добавьте
`using Mjolnir.SDK.World;`.

| `WorldTime` | Что |
|---|---|
| `IsAvailable` | Загружен ли мир. `false` в главном меню |
| `Hour` | Час суток, от 0 (полночь) до 24: 9.5 — половина десятого. Установка сразу переводит часы и сохраняет день; 25 переходит в 1 |
| `IsNight` | Ночь ли сейчас, по счёту игры |
| `DaysPassed` | Дни с начала мира |
| `IsRunning` | Идут ли часы. Остановка удерживает час, солнце и расписания жителей; больше ничего не останавливается |

```csharp
if (WorldTime.IsAvailable && WorldTime.IsNight)
    WorldTime.Hour = 9;   // утро: жители идут на работу
```

Игровой час длится минуту. Жители следуют часам через свои расписания, поэтому рабочий час за секунды отправляет их на
работу, а ночь — спать.

Часы принадлежат хосту. Изменения идут через собственное сообщение игры, то же, что используют её отладочные команды,
поэтому изменение клиента доходит до хоста и возвращается вместе с миром; новый час виден при следующем чтении.
Читайте часы в главном потоке; другой поток получает значение, виденное там в последний раз, а его изменения
выполняются в следующем кадре.

Команда консоли `time` использует те же вызовы: `time day`, `time night`, `time 14:30`, `time stop`, `time run`.
