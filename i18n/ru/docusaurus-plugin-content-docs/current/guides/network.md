# Мультиплеер

`Mjolnir.SDK.Net` проверяет каждую сетевую сессию на совпадение модов и даёт модам каналы сообщений между игроками.
Проверка работает независимо от того, подключает ли мод этот модуль. Чтобы отправлять сообщения, подключите
`Mjolnir.SDK.Net.dll` и добавьте `using Mjolnir.SDK.Net;`.

## Проверка модов {/* #the-mod-check */}

Когда клиент подключается к хосту, оба сравнивают моды, нужные каждому игроку: те, чей манифест объявляет
`NetworkCompatibility.Everyone` (значение по умолчанию).

| Объявлено | Проверяется |
|---|---|
| `Everyone` | Мод есть у обоих игроков, той же версии |
| `ClientOnly`, `ServerOnly` | Никогда: это моды одного игрока |
| Сам Mjolnir | Та же старшая и младшая версия |

- Клиент с совпадающими модами входит, и моды на каждой машине получают о нём событие.
- Клиент с отличающимися модами не входит. Он выходит из сессии и в главном меню видит, какие моды включить или
  выключить и чьи версии различаются. Если он не вышел сам, хост удаляет его через 10 с.
- Клиент без Mjolnir удаляется через 20 с, если у хоста есть моды, нужные каждому игроку, и играет дальше, если нет.
  Сообщения модов ему не приходят никогда.
- Клиент, подключившийся к хосту без Mjolnir, выходит, если у него самого есть моды, нужные каждому игроку.
- Клиент, не получивший ответа от хоста с Mjolnir за 30 с, выходит.

Объявляйте `ClientOnly` для мода, который меняет только то, что видит его игрок (камера, интерфейс), и `ServerOnly` для
мода, работающего только на хосте (правила, инструменты администратора), — тогда он никого не задерживает.

## Игроки {/* #players */}

| `Network` | Что |
|---|---|
| `IsMultiplayer` | Локальный игрок в сетевой сессии. Хост считается, одиночная игра — нет |
| `IsHost` | Локальный игрок — хост сессии |
| `LocalPlayer` | Локальный игрок после прохождения проверки; иначе `null` |
| `Players` | Игроки, прошедшие проверку, включая локального, по id |
| `PlayerJoined`, `PlayerLeft` | Игрок прошёл проверку или вышел. О локальном игроке тоже сообщается |

У `NetPlayer` есть `Id` (id игрока в этой сессии), `IsHost` и `IsLocal`.

## Каналы {/* #channels */}

`Network.Channel(name)` даёт канал вызывающего мода с этим именем — один и тот же объект для одного имени. Сообщение
доходит только до канала того же мода с тем же именем на других машинах, надёжно и по порядку, до 64 КБ.

```csharp title="ShoutMod.cs"
using System.Text;
using Mjolnir.SDK;
using Mjolnir.SDK.Net;
using Mjolnir.SDK.UI;

namespace ShoutMod;

[ModManifest("author.shout", "Shout", "1.0.0")]
public sealed class ShoutMod : Mod
{
    private NetChannel _shouts = null!;

    public override void OnLoad()
    {
        _shouts = Network.Channel("shouts");
        _shouts.Received += (_, e) => Notify.Message($"Player {e.Sender.Id}: {Encoding.UTF8.GetString(e.Data)}");

        DevConsole.Add("shout", "Sends a message to every player.", context =>
        {
            int sent = _shouts.SendToAll(Encoding.UTF8.GetBytes(context.GetRest(0)));
            context.Print($"Sent to {sent} player(s).");
        }, "<text>");

        Network.PlayerJoined += (_, e) =>
        {
            if (Network.IsHost && !e.Player.IsLocal) _shouts.Send(e.Player, Encoding.UTF8.GetBytes("Welcome"));
        };
    }
}
```

| `NetChannel` | Что |
|---|---|
| `Send(player, data)` | Одному игроку. `false` вне сессии, локальному игроку или вышедшему игроку |
| `SendToHost(data)` | Хосту. `false` на хосте или вне сессии |
| `SendToAll(data)` | Всем остальным игрокам, прошедшим проверку; возвращает их число |
| `Received` | Пришло сообщение: `Sender` и `Data`, в главном потоке |

Работайте с каналами в главном потоке. Сообщение, отправленное из другого потока, уходит на следующем кадре, и его
`Send` возвращает `true`. Данные больше 64 КБ бросают `ArgumentException`.

Имена каналов — буквы, цифры, `_`, `-` и `.`, уникальные в пределах мода.

:::note
Проверка и каналы проверены с хостом и клиентом на двух машинах, включая предмет мода и его модель на клиенте. Что
делают другие модули на подключившемся клиенте (работы жителей, модификаторы характеристик), пока не проверено.
:::
