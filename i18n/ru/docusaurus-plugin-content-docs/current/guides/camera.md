# Камера

`Mjolnir.SDK.Camera` даёт модам камеру игрока: где она и что видит, изменения собственных камер игры и камеры мода
поверх них. Подключите `Mjolnir.SDK.Camera.dll` и добавьте `using Mjolnir.SDK.Camera;`.

Камера общая для всех модов. Модификаторы выполняются по порядку приоритета, а из камер модов показывается камера с
наибольшим приоритетом. Всё, что добавил мод, уходит, когда он это освобождает или когда мод отключается после ошибки,
и возвращается камера игры. Камера принадлежит только локальному игроку: по сети от неё ничего не передаётся.

```csharp title="OverheadMod.cs"
using System;
using Mjolnir.SDK;
using Mjolnir.SDK.Camera;
using Mjolnir.SDK.Player;
using Mjolnir.SDK.UI;
using UnityEngine;

namespace OverheadMod;

[ModManifest("author.overhead", "Overhead", "1.0.0")]
public sealed class OverheadMod : Mod
{
    private ModCamera? _above;

    public override void OnGameReady()
    {
        // Более широкий обзор при ходьбе — поверх того, что задали игра и другие моды.
        GameCamera.AddModifier(view =>
        {
            if (view.Mode == CameraMode.Normal) view.FieldOfView += 15;
        });

        HotKeys.Add(KeyGesture.Parse("F8"), ToggleAbove);
    }

    private void ToggleAbove()
    {
        if (_above is { IsActive: true })
        {
            _above.Dispose();   // вид плавно возвращается к камере игры
            _above = null;
            return;
        }
        if (!GameCamera.IsAvailable) return;
        _above = GameCamera.Take(priority: 10, blend: TimeSpan.FromSeconds(1));
    }

    public override void OnUpdate()
    {
        if (_above is not { IsActive: true }) return;
        Vector3 player = LocalPlayer.Position;
        _above.Position = player + new Vector3(0, 20, -8);
        _above.Rotation = Quaternion.LookRotation(player - _above.Position);
    }
}
```

## Чтение {/* #reading */}

| `GameCamera` | Что |
|---|---|
| `IsAvailable` | Есть ли камера игрока: мир с локальным игроком. `false` в главном меню |
| `Position`, `Rotation`, `Forward` | Где стоит и куда смотрит камера, которую показывает экран |
| `FieldOfView` | Её вертикальный угол обзора в градусах, как он нарисован сейчас |
| `Mode`, `ModeChanged` | Камера игры, выбранная сейчас, и её смена: игрок целится, строит, заходит в пещеру. Не вызывается при загрузке мира и выходе из него |
| `ShownCamera` | Камера мода, которую показывает экран, или `null` для камеры игры |
| `WorldToScreen(world)` | Точка мира на экране в пикселях от левого нижнего угла. `z` — насколько она перед камерой, отрицательное — позади |
| `ScreenPointToRay(screen)` | Луч от камеры через точку экрана |
| `TryRaycast(maxDistance, out point, out target)` | На что смотрит середина экрана, где прицел игры. Локальный игрок не учитывается |

Читайте камеру в главном потоке; другой поток получает то, что она показывала там последним.

### Режимы {/* #modes */}

У игры своя камера на каждое занятие игрока, у каждой свои угол обзора, расстояние и смещение:

| `CameraMode` | Когда |
|---|---|
| `Normal` | Ходьба: за плечом, приближается колесом мыши |
| `Aim` | Прицеливание из лука: ближе и уже |
| `Climbing` | Лазание |
| `LockOn` | Захват цели в бою |
| `Build` | Строительство: дальше и выше |
| `Inside` | Внутри постройки |
| `Cave` | В пещере |
| `Fly` | Полёт в облике ворона |
| `Lookout` | На смотровой башне |
| `Boat` | На лодке |

## Модификаторы {/* #modifiers */}

`GameCamera.AddModifier(modify, priority)` меняет камеры игры каждый кадр. `modify` получает каждую камеру как
`CameraView` — со значениями, заданными игрой и оставленными модификаторами с меньшим приоритетом, — и меняет её на
месте:

| `CameraView` | Что |
|---|---|
| `Mode` | Какая это из камер игры |
| `IsCurrent` | Та ли это камера, которую игра выбрала сейчас |
| `FieldOfView` | Вертикальный угол обзора, от 1 до 179 градусов. У камеры ходьбы — 45 |
| `Distance` | Насколько позади игрока стоит камера. Зум игры двигает камеру ходьбы от 2,1 до 10,8 м; `0` — вид из головы |
| `ShoulderOffset` | Точка вращения камеры относительно игрока, в его осях: x вправо, y вверх, z вперёд. У камеры ходьбы (-0,5, 0, 0) — над левым плечом |

- Модификаторы складываются: если два мода расширяют обзор, учитываются оба. Больший приоритет выполняется позже,
  поэтому за ним последнее слово.
- Собственные значения игры возвращаются каждый кадр перед модификаторами, поэтому изменения не накапливаются, а зум
  игры работает со своими числами.
- Освободите возвращённый `CameraModifier`, чтобы убрать изменение; значения игры вернутся в следующем кадре.
- `CameraView` действителен только пока выполняется модификатор: не сохраняйте его.
- Модификатор, бросивший исключение, отключает свой мод.

## Собственная камера мода {/* #a-camera-of-the-mods-own */}

`GameCamera.Take(priority, blend)` показывает собственную камеру мода поверх камеры игры, начиная с того места, где
стоит камера игрока, пока её не освободят. Вид переходит к ней и обратно за `blend`; по умолчанию — сразу.

| `ModCamera` | Что |
|---|---|
| `Position`, `Rotation` | Где она стоит и куда смотрит. Двигайте её каждый кадр или позвольте следовать за объектом и смотреть на него |
| `FieldOfView` | От 1 до 179 градусов; сначала как у камеры игрока |
| `Follow`, `FollowOffset` | `Transform`, у которого она встаёт каждый кадр, плюс смещение в осях мира. `null` — стоит на месте |
| `LookAt` | `Transform`, на который она смотрит каждый кадр. `null` — сохраняет `Rotation` |
| `Priority`, `Blend` | Как переданы в `Take` |
| `IsActive` | Не освобождена, её мод не отключён, мир не покинут |
| `IsShown` | Показывает ли её экран сейчас |
| `Ended` | Вызывается один раз, когда она заканчивается, по любой причине |

- Экран показывает камеру мода с наибольшим приоритетом, а из двух равных — более новую. Камера игры возвращается,
  когда камер модов не остаётся.
- Игрок по-прежнему ходит, целится и строит: игра читает ввод, что бы ни показывал экран.
- Камера заканчивается, когда её освобождают, когда её мод отключается или когда игрок покидает мир. Взятая в главном
  меню, она заканчивается в следующем кадре.

:::note[Ещё не сделано]
- Камера мода остаётся после смерти игрока.
- Ограничения высоты и зума в модификаторе.
- Вид от первого лица со скрытой головой, свободная камера, тряска камеры и фоторежим.
:::
