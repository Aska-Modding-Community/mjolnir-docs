# Консоль разработчика

Клавиша `` ` `` открывает консоль для проверки и отладки: команды Mjolnir и модов, с их ответами. Клавиша — настройка на
собственной странице настроек Mjolnir (кнопка **Настройки** в окне модов). Вверх и Вниз листают историю команд, Esc или
та же клавиша закрывают консоль, окно перетаскивается за рамку.

Консоль работает только на английском: и её ответы, и названия предметов, которые она принимает и показывает.

## Встроенные команды {/* #built-in-commands */}

| Команда | Что |
|---|---|
| `help [command]` | Перечисляет команды или описывает одну |
| `clear` | Очищает консоль |
| `give <item> [count]` | Даёт игроку предмет: по имени ассета (`Item_Wood_Sticks` или `Wood_Sticks`), английскому названию или предмет мода (`<mod id>.<name>`). Несколько совпадений перечисляются, а не угадываются |
| `items [words]` | Перечисляет предметы, имя ассета или английское название которых содержит эти слова |
| `pos` | Где стоит игрок, `x y z`, y вверх |
| `tp <x> [y] <z>` | Телепорт на землю в `x z` или точно в `x y z`. `~` — собственная координата игрока, `~10` — десять метров от неё |
| `time [day\|night\|stop\|run\|<hour>\|<hh:mm>]` | Показывает часы мира, ставит час, останавливает их или запускает снова |
| `stats [villager]` | Показывает персонажа: базовые характеристики, навыки, эффекты. Без имени — игрока |
| `skill [skill] [level]` | Показывает навыки игрока или ставит уровень |
| `effects [words]` | Перечисляет эффекты состояния, названия которых содержат эти слова |
| `effect <effect> [seconds]` | Накладывает на игрока эффект состояния — на секунды или пока его не снимут |
| `uneffect <effect>` | Снимает с игрока эффект состояния |
| `villager [count]` | Создаёт жителей перед игроком |
| `villagers` | Перечисляет жителей мира: что они делают и где |
| `interactions` | Перечисляет взаимодействия модов: где они и кто ими пользуется |
| `anims [words]` | Перечисляет анимации, в именах которых есть эти слова |
| `anim <animation> [loop] [upper] [move] [villager]` | Проигрывает анимацию на игроке или на ближайшем жителе |
| `animstop [villager]` | Останавливает её |
| `emote <sit\|wave\|cheer\|skal> [villager]` | Проигрывает одну из эмоций игры |
| `combatants [radius]` | Перечисляет игроков, жителей, питомцев, существ и логова рядом с игроком |
| `hurt <amount> [near]` | Наносит урон игроку или бьёт ближайшего другого участника боя от имени игрока |
| `heal [amount] [near]` | Возвращает здоровье игроку или ближайшему другому участнику боя |
| `kill` | Убивает ближайшего другого участника боя в пределах 30 м |
| `ground [x z]` | Земля под игроком или в точке: её высота, вид, уклон, биом и вода |
| `raise [metres] [size]`, `lower [metres] [size]` | Поднимает или копает квадрат перед игроком |
| `level [height\|~offset] [size]` | Выравнивает квадрат перед игроком, по умолчанию до его ног |
| `paint <natural\|dirt\|bedrock\|path\|road> [size]` | Делает квадрат перед игроком землёй этого вида |
| `clearveg [size]`, `grass [size]` | Убирает траву и кусты квадрата или возвращает ему природную землю и траву |
| `smooth [strength] [size]` | Сглаживает квадрат перед игроком |
| `biome [name\|number] [size]` | Перечисляет биомы этой части мира и биом здесь или даёт квадрату один из них |
| `objects [radius] [name]` | Перечисляет деревья, камни и растения мира вокруг игрока |
| `field [place [size]\|level\|finish\|remove]` | Перечисляет поля выравнивания игры или ставит одно, выравнивает, заканчивает или убирает ближайшее |
| `undo` | Возвращает землю, которую изменила последняя команда консоли |

Слова разделяются пробелами; слово с пробелами берётся в двойные кавычки: `give Item_Wood_Sticks 5` даёт пять палок.

## Собственные команды {/* #commands-of-your-own */}

`DevConsole.Add(name, description, run, syntax)` добавляет команду. Командам нужна только основная библиотека,
`Mjolnir.SDK`:

```csharp
DevConsole.Add("heal", "Sets the player's health to its maximum.", context =>
{
    LocalPlayer.Health.Value = LocalPlayer.Health.Maximum;
    context.Print("Healed.");
});

DevConsole.Add("wood", "Gives logs.", context =>
{
    int given = Items.Give("Item_Wood_Logs", context.GetInt(0, 10));
    context.Print($"Gave {given} logs.");
}, "[count]");
```

- Имя — это буквы, цифры, `_` и `-`, в любом регистре. Первая команда с таким именем владеет им. Каждая команда также
  отвечает на своё полное имя, `<mod id>:<name>`, так что конфликт имён никогда не скрывает команду мода.
- `syntax` описывает то, что следует за именем, — для `help` и для строки использования после неверного ввода.
- `Add` возвращает `DevCommand`; `DevConsole.Remove(command)` убирает её.
- Команды выполняются в главном потоке. `DevConsole.Execute(line)` выполняет строку так, будто она набрана, из любого
  потока.

## Контекст {/* #the-context */}

| `DevCommandContext` | Что |
|---|---|
| `Arguments`, `Line`, `Command` | Слова после имени, вся строка, команда |
| `GetString(i)`, `GetInt(i)`, `GetFloat(i)` | Слово с индексом `i`, 0 — первое после имени. Бросают `DevCommandException`, когда его нет или оно не число |
| `GetInt(i, fallback)`, `GetFloat(i, fallback)` | То же со значением на случай отсутствующего слова |
| `GetRest(i)` | Слова начиная с `i`, соединённые пробелами |
| `Print(text)`, `Error(text)` | Ответ, обычный или цветом ошибки |

`DevCommandException` показывает своё сообщение и строку использования; мод остаётся включённым. Любое другое
исключение показывается и отключает мод — так же, как исключение в любом другом его коде.

Каждая строка консоли также пишется в `Mjolnir/LogOutput.log` как `[Console]`, ошибки — как предупреждения.
`DevConsole.Print(text)` добавляет строку откуда угодно.
